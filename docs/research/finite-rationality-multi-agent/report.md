# 异构大模型智能体系统的有限理性博弈与协同机制研究

青年基金研究方案论证稿\
修订日期：2026年10月8日

## 1. 摘要

异构大模型智能体通过共享证据、衔接推理与交叉验证，能够汇集不同模型的知识和推理能力。然而，信息共享也会改变成员对同伴判断的依赖，影响后续核验与结论修正，使局部错误转化为系统性偏差。如何将异构个体的能力互补转化为可靠的协同推理能力，需要揭示信息利用与策略响应之间的作用机制。本项目面向共同目标下的异构大模型智能体系统，研究证据交互中的有限理性响应及其协同效应：通过证据内容、结论披露与核验条件的受控干预，辨识信息采纳和验证行为，建立可检验的异构响应模型；将行为模型嵌入共同收益的核验博弈，研究验证行动的相互依赖及其对错误传播与交叉纠错的影响，刻画有效协同的条件；据此联合设计信息披露时序与验证职责，在资源约束和行为预测误差下促进证据互补与可靠纠错。项目结合可控推理任务与协同代码诊断开展验证，贯通行为辨识、机理分析和机制设计，为增强异构大模型智能体系统的协同推理能力提供理论依据与方法支撑。

**关键词：** 异构大模型；智能体系统；协同推理；有限理性博弈；协同机制

## 2. 拟解决的问题及其重要性

### 2.1 研究背景：个体能力为何未必转化为协同推理能力

大模型智能体系统通过组织多个模型共同完成任务，为整合异构知识、分解复杂推理和交叉检查结果提供了新的技术途径。多智能体辩论、可编程交互框架及角色化工作流已展示出多样的协作方式。[R10](references.md#r10) [R11](references.md#r11) [R12](references.md#r12) 但已有评测也表明，增加成员或交互轮数并不稳定地带来收益；在部分任务上，经过充分配置的单模型推理和独立集成仍是有竞争力的基线。[R18](references.md#r18) [R35](references.md#r35) [R44](references.md#r44)

这一差距不仅涉及个体推理能力，也涉及能力在交互中的使用方式。以代码诊断为例，一个智能体提出修复方案，另一个智能体检查边界条件。提前共享实现者的解释，可能帮助核验者发现关键依赖，也可能使其沿用未经证实的假设；完全隔离双方判断，能够减少直接影响，却可能遗漏只有交换信息才能发现的问题。因此，信息共享的作用取决于成员如何理解证据、判断同伴的可靠性，以及据此选择是否继续核验。

本项目关注的核心矛盾是：**证据共享促进信息互补，但由此形成的判断依赖可能改变独立核验与纠错行为，影响协同推理收益。** 其中，独立核验指成员在接触同伴结论之前形成检查结果，或使用独立获取的工具证据进行检查；它是一种可控制的程序安排，其结果是否具有统计独立性仍需测量。

围绕这一矛盾，项目研究由少量冻结的异构大模型驱动、具有共同任务目标的智能体系统，重点考察证据采纳、交叉核验与结论修正。有限理性具体指成员在有限信息处理与核验能力下，对证据价值、同伴行为和行动后果的判断与选择可能偏离任务最优响应。协同推理能力具体体现为：综合分散证据的能力、衔接成员推理结果的能力，以及通过交互纠正错误并保持正确判断的能力。研究以增强这些能力为主线，将预算作为机制可实施性和实验公平性的约束。

### 2.2 关键科学问题及其重要性

#### 问题一：证据交互下的有限理性响应如何辨识？

智能体改变判断，可能源于获得了新证据，也可能源于重复接受相同信息、依赖同伴结论或未能完成必要核验。仅观察最终答案，难以区分这些原因；给不同任务分别拟合一个“理性程度”，也难以形成可检验的解释。

本项目研究在信息与行动边界明确的任务中，如何通过受控干预区分证据增量、同伴影响和推理资源的作用，确定哪些响应规律能够在任务与交互条件变化后继续预测行为。重点辨识的是条件性行为差异及其稳定范围，而非从输出反推不可观测的内部认知状态。

这一问题决定后续博弈分析能否获得真实的行为依据。若不能区分“证据不足”和“证据使用不当”，机制可能在应补充事实时增加讨论，或在应独立核验时强化共识。

#### 问题二：验证行动的相互依赖如何影响协同推理？

一个成员继续核验的价值，取决于其他成员已经检查了什么、检查是否可靠，以及检查结果如何被利用。当两项检查覆盖不同的必要推理环节时，其作用可能相互补充；当检查重复覆盖同一环节时，其边际价值可能相互替代。智能体对这种依赖关系的误判，可能造成核验遗漏、重复投入或错误结论的持续传播。

本项目研究异构成员的有限理性响应如何与任务中的验证依赖共同作用，刻画局部偏差被纠正或放大的条件，并分析稳定的策略组合为何可能具有不同的推理质量。共同目标下仍存在策略相互依赖：一个成员核验的边际价值取决于其他成员的行动，而局部信息与有限计算使实际响应可能偏离团队最优安排。博弈分析用于揭示这种依赖；均衡描述相互响应的策略状态，推理质量则由正确性和纠错结果评价。

这一问题将个体行为与系统推理能力联系起来，使“何时共享、由谁核验、何时继续交互”的选择具有可解释的依据。

#### 问题三：如何依据行为与交互机理设计可靠的协同机制？

统一要求所有成员充分讨论或重复核验，既未必有效，也会占用完成关键推理的资源。不同任务、成员组合及证据条件需要不同的交互安排，而行为预测本身存在误差。

本项目研究如何联合选择结论披露时点与验证职责，在保留有用信息交换的同时减少无依据的相互依赖，并明确机制在何种预测误差与资源条件下仍具有收益。机制依据运行时可获得的证据、已完成的核验及校准数据作出选择，并以独立结果检验这些选择的有效性。

三项问题依次提供行为依据、作用规律和设计方法，共同支撑异构大模型智能体系统协同推理能力的提升。

### 2.3 国内外研究现状与项目定位

**有限理性理论为行为分析提供基础，但模型必须具有可检验性。** Simon 将计算与信息处理限制引入决策研究；量化响应均衡以概率响应描述非精确优化，认知层级与信息处理成本理论分别刻画策略推理深度和资源约束。[R01](references.md#r01) [R03](references.md#r03) [R04](references.md#r04) [R05](references.md#r05) 既有研究同时指出，缺少适当限制时，量化响应模型能够解释过于广泛的行为；跨博弈的可控变化与参数不变性是进行辨识和检验的重要条件。[R31](references.md#r31) [R46](references.md#r46) 大模型行为研究也表明，提示中声明的任务目标与实际策略响应需要分别检验；描述性偏好参数不宜直接解释为内部认知。[R21](references.md#r21) [R24](references.md#r24) 因而，本项目采用受约束的行为模型和留出干预测试，检验其预测价值。

**协同推理研究已从组织流程扩展到信息利用与失效分析。** iAgents 研究信息不对称下的协作；MAST 从执行轨迹归纳系统设计、智能体间失配和任务验证等失败模式。[R16](references.md#r16) [R17](references.md#r17) 多智能体迎合、逻辑推理控制实验及辩论与投票比较进一步揭示了同伴影响、初始能力和交互方式的作用。[R19](references.md#r19) [R35](references.md#r35) [R39](references.md#r39) 这些工作为实验设计提供了依据，但失败分类或准确率差异本身不足以说明验证行动之间的策略依赖。

**博弈均衡已被直接用于大模型协作。** ECON 通过信念建模与层级协调研究贝叶斯纳什均衡；其扩展工作 DICE 进一步研究异构量化响应均衡、条件性收敛及实际更新中的近似误差。[R34](references.md#r34) [R22](references.md#r22) 量化响应决策聚合则在条件独立同分布信号等设定下分析聚合规则。[R23](references.md#r23) 因此，将博弈或有限理性引入多智能体系统，以及一般性的均衡存在、收敛和误差分析，均已有明确基础。本项目进一步关注证据交互与核验选择的相互作用，以受控实验获得实际响应的依据，解释信息披露如何改变后续核验，以及核验产生的新证据如何影响协同纠错。

**证据组织与独立核验已有有效方法，其作用条件仍值得进一步研究。** CoVe 通过分离验证过程减少原答案的影响；ColMAD、GAVEL 分别探索面向共同求解的证据协作和可追溯核验；InfoDelphi 通过公共与私有证据分配组织交互。[R45](references.md#r45) [R36](references.md#r36) [R43](references.md#r43) [R37](references.md#r37) 置信度与不确定性研究强调信息多样性和可靠信息利用之间的关系。[R38](references.md#r38) [R40](references.md#r40) 近期审计研究还发现，屏蔽上游结论的效果随其可靠性和任务条件而变化。[R42](references.md#r42) 已有方法提供了证据组织与核验的实现基础，进一步需要回答这些安排如何与异构成员的响应及核验分工相匹配。

信息获取博弈已研究信息选择的策略依赖，并表明其与后续行动之间的关系受到收益结构和参与者规模等条件影响。[R47](references.md#r47) [R48](references.md#r48) 因而，本项目分别刻画任务环节的依赖、核验组合的收益关系和智能体的实际响应，以避免从任务互补直接推断核验互补。

社会学习与人机协作理论进一步提供了相关参照：重复信息的影响、收敛与正确性的区别，以及信息增益与行为偏差之间的关系，已有条件明确的分析。[R32](references.md#r32) [R33](references.md#r33) [R41](references.md#r41) 本项目据此研究大模型智能体在有限轮交互中的实际响应，以及验证行动如何改变后续可用证据，避免直接套用大群体极限或理想贝叶斯更新结论。

### 2.4 研究价值与范围

项目的理论价值在于解释信息共享如何经由有限理性策略响应影响证据整合与交叉纠错，将个体行为、验证依赖与系统推理质量联系起来。方法价值在于形成依据行为与任务条件组织协作的设计准则，为异构模型的能力互补提供可检验的机制依据。

研究以二至四个智能体、有限轮交互和可验证任务为主要范围。底层大模型参数保持冻结，重点调整证据披露与验证安排。可控任务用于辨识行为和检验理论，协同代码诊断与修复用于检验方法的外部适用性。研究不依赖大规模模型训练，也不将支付激励、多组织利益冲突或无限时域在线学习纳入主要任务。

## 3. 研究内容、技术路线与验证方案

### 3.1 研究内容及其关联

项目按照“有限理性响应辨识—核验博弈与纠错机理—协同机制设计”的递进关系展开，围绕“信息披露改变核验选择，核验改变证据供给，新增证据影响后续纠错”的作用过程组织研究。三部分使用一致的行动定义与证据记录：第一部分提供行动概率和预测误差，第二部分分析这些响应在交互中形成的系统效应，第三部分据此选择可执行规则，并以独立任务结果检验前两部分的解释。

| 研究内容                         | 主要研究对象                 | 形成的结果                     | 对后续研究的支撑               |
| -------------------------------- | ---------------------------- | ------------------------------ | ------------------------------ |
| 一：证据交互下的有限理性响应辨识 | 采纳、核验和修正行为         | 响应模型、干预效应与可信范围   | 为博弈分析提供行为参数及其约束 |
| 二：核验策略依赖与协同纠错机理   | 验证互补、验证替代与错误传播 | 协同条件、失效边界及可观测判据 | 为披露和验证安排提供选择依据   |
| 三：面向协同推理的信息与验证机制 | 披露时序、验证职责与停止规则 | 有限预算下的协同机制及适用范围 | 用端到端结果检验模型与机理     |

#### 研究内容一：证据交互下的有限理性响应辨识

本部分研究智能体如何使用同伴提供的证据与结论，建立能够支持后续交互分析的行为模型。

**（1）构建证据与行为因素可分离的干预体系。** 设计可程序生成的局部信息推理任务，明确证据来源、推理依赖与正确结果。通过具有确定答案的规则判断和工具执行检查，分别测量基础任务能力与核验能力，再开展交互干预。围绕同一任务和同一初始候选结果，分别改变新增证据、同源证据的重复呈现、同伴结论的可见性以及核验预算。保持证据不变的披露实验用于测量结论影响；补足事实的对照用于测量信息约束；分档预算实验用于考察计算投入的作用。对关键因素开展联合干预，识别其相互作用，检验同伴影响是对可靠信息的利用，还是缺少依据的结论采纳。

**（2）建立受实验约束的异构响应模型。** 将请求证据、执行核验、采纳或保留判断、修正结论等行为映射为有限行动。以量化响应作为可解释起点，分别描述对行动价值差的敏感性和对同伴信息的条件性响应；用证据重复程度、结论可见性和已完成核验等低维变量表示交互条件。可控任务固定收益尺度和任务规则；真实任务通过独立校准数据估计行动后果。模型参数优先在同一模型和预算档位内跨任务共享，并检验职责变化的影响，仅在数据支持时增加交互项，避免以任意复杂函数吸收全部偏差。

**（3）检验可辨识性与跨条件预测。** 分析不同干预能否区分候选参数，结合似然剖面、模拟恢复与留出实验检查估计稳定性。将部分任务结构及披露、预算与成员的未见组合完整留出，检验模型能否预测尚未观测的行为变化。与固定参数量化响应、灵活统计模型进行对照，区分解释性结构带来的收益与单纯增加模型容量的收益。对于无法分离的因素，报告可识别的响应差异或参数范围。

本部分形成带有适用条件的行为模型与校准数据。其行动概率、干预效应和误差范围将直接进入研究内容二的核验博弈，并用于研究内容三评价候选交互安排。

#### 研究内容二：核验策略依赖与协同纠错机理

本部分基于行为模型，研究成员的核验选择如何相互影响，以及这种影响如何改变系统的推理结果。

**（1）建立证据共享与核验选择的团队博弈。** 以共同任务质量为收益基础，描述成员的局部信息、可行核验行动及其成本。围绕不同检查共同覆盖必要环节、或重复覆盖同一环节的任务结构，分别估计核验组合的收益，判断验证互补与验证替代何时成立。研究同伴结论的披露如何改变成员对核验价值的判断，并比较实际任务依赖与估计响应之间的差异。通过二智能体有限行动模型建立分析起点，再扩展至少量异构成员。核验所得证据进入下一轮的信息集合，使证据供给随成员行动发生变化，从而联系当前策略选择与后续推理质量。

**（2）刻画错误传播与交叉纠错的条件。** 将行为响应嵌入有限轮交互过程，区分新增证据促成的纠错、未经核验的采纳和正确判断被覆盖等路径。研究证据重用程度、核验能力差异及响应偏差如何共同影响这些路径。对满足模型假设的任务分析响应均衡及其质量；对不满足稳定性条件的情形，直接分析有限轮结果和失败概率。围绕同伴结论可靠性、核验结果相关性与响应敏感性，研究两类转变条件：披露引起的核验减少何时体现有效分工、何时导致关键检查缺失；保留独立判断何时提供新增纠错能力、何时只增加重复投入。

**（3）建立能够用于机制选择的判据。** 将理论中的依赖关系联系到实际可测量的量，包括结论披露引起的核验概率变化、不同核验组合的边际收益，以及错误转正确与正确转错误的概率。采用披露与核验的两阶段随机干预，检验拟提出的作用路径，避免把轨迹中的相关关系直接解释为因果机制。分析判据对行为估计误差的敏感性，给出有效区间和失效反例。

本部分形成关于披露时序、验证互补与纠错收益的条件性结论。研究内容三依据这些结论缩小候选机制范围，并确定哪些情形需要保留独立判断、增加指定核验或停止重复交互。

#### 研究内容三：面向协同推理的信息披露与验证机制

本部分将前两部分的行为依据和机理判断转化为可执行协作规则，增强异构智能体的信息整合和纠错能力。

**（1）设计证据与结论分层披露的交互方式。** 将共享内容区分为任务事实、推理结论和核验记录，为证据保留来源与引用关系。在直接共享、先共享证据后披露结论、独立核验后交换判断三类基本安排中，研究哪些信息应提前共享以支持推理衔接，哪些结论应延迟披露以保留核验独立性。证据标识和引用检查采用已有方法，研究重点是披露方式与成员响应、验证职责之间的匹配关系。

**（2）依据核验边际价值配置验证职责。** 综合任务依赖、成员核验能力与同伴影响，选择承担关键检查的成员及必要的补充核验。对于覆盖不同推理环节的检查，优先保证必要环节得到覆盖；对于高度重复的检查，比较其新增纠错收益与资源占用。配置以有限数量的验证名额和预算档位实现，联合比较披露时序与验证安排，避免分别优化两者而忽略行为变化。

**（3）形成考虑预测误差的选择与停止方法。** 对具有校准数据支持的候选安排估计推理质量及其不确定性，在预算内选择保守评价较优的机制。若预测无法区分候选规则，则采用已校准的固定流程；当继续交互缺少新增证据、预计增益不足或预算耗尽时停止。停止结果保留已核验与未解决事项，未解决任务按预定规则纳入评价。以未见任务和成员组合检验机制的适用范围，并核算重新校准成本。

本部分形成协同机制与实验原型。其验证重点是同等资源下的信息整合、交叉纠错和端到端任务质量，并通过消融实验检验行为模型与博弈分析是否对这些能力产生实际贡献。

### 3.2 技术路线

#### （1）统一实验对象与信息边界

对每个任务记录原始证据、证据来源、初始候选结果、成员可见信息及可行行动。证据对应可追溯的任务事实、数据或工具反馈；模型生成的解释先作为待验证主张处理。新增证据按其是否提供先前未获得的任务信息界定，避免将同一事实的改写计为信息增量。先生成并冻结初始候选池，再随机分配披露与核验条件，使不同机制面对可比的起点。严格控制当前智能体可见的消息和工具权限，由执行程序实现信息边界。

“补充事实”“展示同伴结论”“增加一次核验”对应不同干预：前者改变信息集合，第二项改变既有判断的可见性，第三项改变行动及资源投入。实验分别估计其效应，并在联合实验中考察相互作用。对自然语言表述、消息位置和长度进行配对控制，以减少提示形式带来的替代解释。

#### （2）受约束的有限理性响应建模

将证据请求、工具核验和结论修正记录为可观察行动，同时记录消息可见性与接收顺序。验证职责规定检查对象、信息权限和可用预算，智能体仍需选择证据、执行检查并判断是否修正；实验中的强制核验另作为识别行动后果的干预。在给定局部历史 $`h_i`$、机制 $`m`$ 和预算档位 $`b_i`$ 时，以如下量化响应形式作为候选模型：

```math
\pi_i(a_i\mid h_i,m,b_i)=
\frac{\exp\{\lambda_i(b_i)\,\widehat Q_i(a_i\mid h_i,m,\pi_{-i};\theta_i)\}}
{\sum_{a'_i}\exp\{\lambda_i(b_i)\,\widehat Q_i(a'_i\mid h_i,m,\pi_{-i};\theta_i)\}}.
```

其中，$`\widehat Q_i`$ 表示行动的估计价值，$`\lambda_i\geq0`$ 表示在固定价值尺度下对行动差异的响应敏感性，$`\theta_i`$ 仅包含由实验支持的低维信息响应参数。价值尺度、参考行动和参数共享方式在建模前确定；行动后果优先由随机指定核验的独立数据估计，避免同时任意拟合价值和响应参数。通过干预设计检查参数是否能够区分；采样温度作为接口设置记录，不等同于理性参数。

共同收益描述任务规范，不能自动视为模型真实优化的效用。因此，先通过收益变化、核验成本和信息干预检查响应假设，再讨论博弈解释。参数拟合优度与跨条件预测同时报告；对预测偏差明显的设定，进一步通过干预检查函数形式、信息响应的稳定性和策略间的一致性。既有辨识理论提供方法参照，其独立收益变化等条件不能直接套用于共同收益场景。[R31](references.md#r31) [R46](references.md#r46)

#### （3）核验依赖与均衡质量分析

设共同任务收益为正确性与核验成本的规范化组合。对固定任务状态和其他成员策略，记 $`U(v_i,v_j)`$ 为两个成员分别选择核验或不核验时的期望团队收益，其中 $`v_i,v_j\in\{0,1\}`$。以

```math
\Gamma_{ij}
=U(1,1)-U(1,0)-U(0,1)+U(0,0)
```

描述两项核验的收益依赖：$`\Gamma_{ij}>0`$ 对应互补，$`\Gamma_{ij}<0`$ 对应替代。该量是有限博弈的分析工具；项目拟研究的是信息披露如何通过实际响应改变核验组合，以及这种改变对协同推理的影响。

在有限任务模型中，先固定后续结果汇总与修正规则，通过枚举核验组合和受控重复执行估计行动后果；随后结合响应模型分析局部核验博弈的均衡质量及参数敏感性。多轮过程中，核验结果不断改变信息状态，进一步分析这些变化如何影响下一轮响应及纠错，不将整个对话过程等同于在同一个静态博弈中迭代。只有在信念一致性等条件成立时，才将响应固定点解释为相应量化响应均衡。均衡存在性、唯一性和实际交互的可达性分别处理，具体结论注明适用任务类。

有限轮分析以系统结果为中心。设 $`Z_t`$ 表示采用固定结果汇总规则得到的第 $`t`$ 轮结果是否正确，则

```math
\Pr(Z_{t+1}=1)-\Pr(Z_t=1)
=\Pr(Z_t=0,Z_{t+1}=1)-\Pr(Z_t=1,Z_{t+1}=0).
```

依据这一分解，分别建立披露、核验组合与两类转移之间的条件关系，研究新增核验证据带来的纠错收益何时超过交互引入的误导损失，并分析行为估计误差对判据的影响。对于角色输出不同的代码任务，使用候选修复的接受、退回及独立测试结果定义过程指标。

#### （4）由可观测条件驱动机制选择

将三类披露方式与少量验证职责组合为有限机制集合。每个候选机制明确消息可见范围、核验执行顺序和最大轮数；预算同时计入推理、共享、协调与工具执行。离线利用干预数据拟合行为模型，预测候选安排下的核验组合与任务结果；在线仅使用当前证据、已执行检查和剩余预算选择机制。

具体采用“候选筛选—保守评价—有限轮执行”的路径：依据研究内容二的条件排除缺少必要核验的安排，依据研究内容一的误差范围评价剩余候选的推理质量，再选择预算允许的安排。对数据覆盖不足的候选扩大不确定性惩罚；收益下界无法支持调整时保留校准过的固定流程。理论分析限定在有限机制类和明确的数据覆盖条件下，研究机制选择误差与推理质量损失的关系。可控任务中的核验组合枚举用于理论检验；自然任务根据校准数据预测核验价值，在线决策只执行所选安排，完整计入试探性检查成本。

以下三类信息严格区分：运行中可见的证据和工具结果用于决策；校准集答案用于离线估计；测试集答案及隐藏测试仅用于独立评价。以“已知当前答案是否正确”为条件的规则只作诊断上界，不作为可部署机制。

### 3.3 验证方案

#### （1）任务体系与实验规模

构建“可控辨识—自然任务检验”两层任务体系。

第一层采用程序生成的局部证据整合、逻辑判断与协同核验任务。明确真实状态、信息生成方式和行动后果，以需要联合检查才能补齐必要证据、或多个检查均能发现同一错误的任务为起点，构造并检验不同的核验收益结构。通过种子和结构划分校准、开发与测试集合，避免同一模板的近重复样本跨集合出现。逻辑推理控制实验可参照已有研究，但关键干预围绕证据披露与核验选择重新设计。[R39](references.md#r39)

第二层采用可执行的代码诊断与小规模修复任务，设置方案生成、测试与审查职责，利用测试结果评价推理衔接与纠错。以 SWE-bench 的适用子集补充真实仓库任务，任务筛选与排除规则在运行前确定；公开开发测试可供智能体使用，评测测试与参考补丁在运行时隔离；以新生成并经独立验证的缺陷任务补充公开基准，检查结论对任务记忆和测试覆盖的敏感性。[R27](references.md#r27)

主实验选择三个模型家族，先在二智能体设置完成辨识，再验证三至四成员组合。异构性通过证据利用、核验能力与错误相关性刻画，固定模型版本和解码设置，采用同构团队、异构团队与角色互换对照。先导阶段用于估计方差、检查干预强度和核算调用成本；正式样本量依据任务级效应量和统计功效确定，开发阶段结束后冻结主要比较，不对所有因素开展全组合穷举。

#### （2）科学问题与检验证据

| 检验假设                                     | 实验干预或比较                                       | 主要证据                                       | 不支持假设时的解释                             |
| -------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| H1：证据使用与同伴影响具有可预测的条件性差异 | 固定证据，改变结论披露；固定披露，改变新增与重复证据 | 留出条件下的行动预测、干预效应与校准误差       | 简化或限制行为模型，不将拟合参数解释为普遍特征 |
| H2：披露改变核验选择，并通过验证依赖影响纠错 | 随机化披露方式及核验要求，比较互补与替代任务         | 核验组合、纠错和误导转移的变化及其联合预测     | 检查信息增量或直接结论影响是否足以解释结果     |
| H3：机理指导的联合安排具有系统收益           | 比较联合选择、固定流程和分别选择                     | 同预算端到端正确性、未检出错误率及质量成本曲线 | 报告无增益区间，分析模型误差和协调开销         |
| H4：误差控制改善未见组合上的可靠性           | 去除保守评价，或更换未参与校准的成员组合             | 性能退化、候选排序误差与校准成本               | 限定迁移范围，采用任务或成员分组校准           |

H2采用两阶段随机干预，分别估计披露的总效应、指定核验条件下的受控效应及二者交互，检验所提出的作用路径。可控任务由执行程序落实指定检查；自然任务同时记录分配的核验要求与实际执行情况，以随机分配为依据报告干预效应。仅通过自然轨迹观察到“核验较多的任务更准确”，不能据此认定核验的因果效应；任务难度、初始正确性和证据条件须在实验设计中控制。

#### （3）比较方法与资源匹配

设置三类主要对照。

第一类为强单模型方法，包括独立求解、自一致性采样、多次采样加验证及 CoVe 类独立核验。在开发集选择表现最强的成员模型与推理配置，将团队初始可用证据的并集提供给相应集中式对照，并给予可比工具和预算，以检验协作收益是否只是额外信息或计算带来的结果。[R25](references.md#r25) [R26](references.md#r26) [R29](references.md#r29) [R45](references.md#r45)

第二类为固定多智能体方法，包括无通信异构集成、固定轮数交互、固定独立核验，以及 ColMAD 类证据协作。对初始候选池可复用的比较保持候选一致；需要额外生成的步骤完整计费。DICE等方法在动作、训练条件与观测权限能够对齐的设置中开展专项比较，分别报告训练和推理开销。[R22](references.md#r22) [R36](references.md#r36)

第三类为同等数据条件下的非博弈自适应控制器，使用相同输入、候选机制与校准预算直接预测规则收益。该对照用于检验博弈结构是否改善样本利用、未见条件预测或机制选择，而非仅比较固定规则与更强的自适应系统。

代码任务进一步纳入 Self-Debugging 类执行反馈调试；在任务接口适配的设置中比较 MapCoder 类规划与调试流程，明确其由程序生成转为诊断修复时的调整，并保持可见测试一致。[R49](references.md#r49) [R50](references.md#r50)

对所有方法记录输入与输出token、核验工具调用、失败重试、协调器开销及端到端时延。异构模型的token数不直接等同计算量，分别报告实际费用或统一硬件下的时间口径。离线校准与在线执行分开核算，并报告不同任务量下的摊销成本。

#### （4）指标、消融与统计分析

**主要结果指标**为预定预算下的任务正确率或修复成功率，报告相对预先选定强基线的配对差异与95%置信区间。代码任务同时统计错误候选中的被接受比例与已接受结果中的错误比例，避免用讨论一致性代替系统可靠性。

**过程指标**包括必要证据覆盖、正确转错误和错误转正确的概率、有效核验覆盖率、重复核验比例及未解决任务比例。自报置信度需经独立结果校准；证据来源数量和文本差异仅作辅助变量，不能直接替代信息独立性或推理质量。

**模型指标**包括行动预测的负对数似然、Brier分数、校准误差和留出干预效应的预测误差。机制评价进一步检查候选规则排序是否准确，以及预测改进是否落在真正影响最终结果的决策上。

消融实验依次移除行为条件化、验证依赖分析、披露与职责联合选择、预测误差处理，保持可用信息、候选规则和数据量可比。除随机划分外，采用整类任务结构留出及整组成员组合留出，检验迁移能力。

以任务为统计单位进行配对分析；同一任务的多轮消息和重复采样作为相关观测处理，采用任务级重采样或分层模型估计区间。主要假设与比较预先固定，探索性分析单独标注并控制多重比较。解析失败、超时和未解决任务纳入主结果，同时报告有效输出条件下的敏感性分析。

保存模型版本、提示模板、任务种子、消息可见范围、证据引用、实际行动、工具结果与全部开销，使实验能够按任务重放，并将理论预测与具体轨迹对应。

### 3.4 预期创新与研究成果

项目拟在以下三个相互关联的方面形成研究增量。

**第一，建立面向证据交互的有限理性响应辨识方法。** 在共同任务目标下，利用证据与结论的配对干预约束行为模型，区分信息增量与同伴影响，明确可识别的响应规律及其跨条件预测范围。

**第二，揭示验证策略依赖影响协同推理的作用机制。** 将核验行动及其产生的新证据纳入同一分析过程，研究异构响应、验证互补与验证替代如何共同决定纠错收益，并给出连接可控博弈与实际交互的条件性判据。

**第三，形成行为与机理共同指导的信息披露和验证机制。** 将披露时序与验证职责联合选择，在预测误差和资源约束下组织证据交换与交叉纠错，明确其相对固定独立核验及非博弈自适应方法的增量作用。

预期成果包括：一套具有可辨识条件和预测范围的行为建模方法；一组明确任务范围的协同机理结论、反例及实验验证；一种可执行的联合协同机制；配套的干预任务、行为数据规范和可复现评测原型。成果评价以假设是否得到支持、方法是否改善独立测试表现及其适用边界为依据。

### 3.5 三年实施计划与可行性

| 阶段               | 主要任务                                                                         | 阶段成果与验收依据                                                 |
| ------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 第一年：行为辨识   | 完成核心文献与基线复现；构建可控任务和信息边界；开展先导与正式干预；建立响应模型 | 可重放的干预数据；明确的参数约束；留出条件预测与适用范围检验       |
| 第二年：机理分析   | 建立核验博弈；分析互补与替代结构；研究有限轮纠错；完成两阶段干预                 | 有条件的理论结论与反例；关键作用路径的实验检验；候选机制及选择判据 |
| 第三年：机制与验证 | 完成披露和验证联合设计；开展代码任务验证、成员组合迁移和消融；整理开放成果       | 同预算强基线比较；机制收益与无效范围；可复现原型和研究论文         |

技术可行性主要来自三个方面：可程序生成的任务能够提供确定结果与受控信息结构；有限行动、少量成员和有限轮交互使博弈分析及机制搜索具备可操作性；冻结模型与标准化执行工具有利于控制训练成本和复现条件。代码任务提供外部执行反馈，能够检验机制在自然语言交互中的有效性。

实施采取递进安排。第一年优先确认行为干预是否产生可重复、可预测的差异；第二年围绕得到支持的行为结构开展理论分析；第三年使用已经冻结的机制进行独立验证。资源投入优先用于关键假设、强基线和必要消融，模型数量与任务规模依据先导成本和统计功效确定。

上述为研究方案的技术可行性。申请人的代表性成果、已有先导数据和实际算力条件，应依据真实材料补充，并与三项研究逐一对应；相关准备事项见 [申请完善说明](application-notes.md)。

### 3.6 主要风险与应对

| 风险                           | 对研究结论的影响             | 应对方案                                                         |
| ------------------------------ | ---------------------------- | ---------------------------------------------------------------- |
| 行为参数不可辨识或跨条件不稳定 | 无法支持细粒度机制解释       | 缩减参数，报告可识别的干预效应与预测范围，限定任务类             |
| 核验选择并非主要作用路径       | 原有机理假设不成立           | 用随机化核验检验直接效应与间接路径，保留负结果并修正模型         |
| 理论条件与自然任务存在差距     | 可证明结论不能直接推广       | 分别报告有限模型结论和自然任务证据，以反例界定适用边界           |
| 证据检查不可靠或相关性过高     | 交叉核验难以提供新增纠错能力 | 测量核验器能力与错误相关性，优先使用可执行反馈并限定机制启用条件 |
| 协同收益不足以覆盖开销         | 方法在部分预算区间不具优势   | 完整报告质量成本曲线，保留独立求解或固定流程作为候选             |
| 模型版本或任务分布变化         | 校准失效、复现困难           | 固定公开权重与版本记录，开展留出组合检验并单独核算重新校准成本   |

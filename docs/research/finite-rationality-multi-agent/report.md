# 异构大模型智能体系统的有限理性博弈与协同机制研究

青年基金研究方案论证稿\
修订日期：2026年10月9日

## 1. 摘要

异构大模型智能体的能力与信息差异为协同推理提供了互补基础，但有限的信息处理与策略推理能力可能使成员误判任务价值和同伴策略，导致分工失配与信息利用偏差，制约系统协同效果。本项目面向具有共同任务目标的异构大模型智能体系统，研究任务分工与信息交互的有限理性博弈机制。首先，分析成员对任务价值和同伴策略的判断如何影响行动选择，建立刻画异构成员策略响应的博弈模型；其次，基于该模型研究任务分工与信息交互的相互作用，分析其对均衡形成及推理质量的影响，揭示异构能力转化为协同推理增益的条件；最后，依据上述机理设计任务协调与信息交互机制，研究有限交互预算与响应偏差下的协同策略更新方法。通过可控推理任务与协同代码诊断检验模型、机理与方法，为增强异构大模型智能体系统的协同推理能力提供理论依据与方法支撑。

**关键词：** 异构大模型；智能体系统；协同推理；有限理性博弈；协同机制

## 2. 拟解决的问题及其重要性

### 2.1 研究背景：能力互补如何转化为有效协作

大模型智能体系统通过分解任务、组织信息交换和衔接成员推理，为解决复杂问题提供了新的途径。现有研究已形成角色化工作流、可编程交互、协作图优化和动态任务路由等方法，能够在不同层次组织多个模型共同求解。[R11](references.md#r11) [R12](references.md#r12) [R53](references.md#r53) [R54](references.md#r54) 但更多成员、更频繁交互或更复杂的协作结构，并不稳定地带来更好的任务结果；充分配置的单模型推理与独立集成仍是必要的比较基准。[R18](references.md#r18) [R35](references.md#r35) [R44](references.md#r44)

这一差距涉及成员能力，也涉及成员决策之间的相互依赖。以代码诊断为例，擅长缺陷定位的成员是否应继续定位，取决于同伴是否已经获得可靠线索、后续修复是否需要补充分析，以及测试成员能否识别候选方案的问题。重复定位可能浪费资源，也可能在证据不足时提供必要交叉检查；过早转入修复则可能使整个团队沿用错误假设。因此，分工的价值不能仅由单个模型的能力排序决定，还取决于其他成员承担的任务及其产生的信息。

**共同目标并不消除策略依赖。** 每个成员都希望任务成功，但在局部信息和有限推理能力下，可能高估同伴已完成的工作，低估某项补充推理的价值，或不能准确预判角色调整后的结果。这些判断会影响自身任务选择和信息使用，进而改变同伴下一步的行动条件。由此形成“任务选择影响信息产生，信息交互改变后续分工”的反馈。分工失配、重复投入和关键环节缺失，是这一反馈可能产生的不同结果，而非预先假定所有系统均存在的缺陷。

博弈论为研究上述关系提供了明确的分析对象：参与者的行动选择、对他人策略的判断、联合行动的收益，以及相互响应形成的均衡。势博弈与博弈学习已被用于共同目标下的多智能体控制，说明合作任务同样可以通过策略依赖进行分析。[R06](references.md#r06) [R52](references.md#r52) 本项目据此研究智能体如何在有限理性条件下形成分工和交互策略，并通过改变协调与信息条件改善协同推理。工作流、路由规则与图优化方法构成实现基础和重要对照；博弈分析需要进一步给出关于策略响应、均衡效率及协同改进的可检验结论。

项目的核心科学问题是：**在能力异构与有限理性条件下，任务分工和信息交互如何通过成员间的策略依赖，促进或限制系统协同推理？** 其中，有限理性指在给定信息和资源条件下，对行动价值、同伴策略及其后果的评估与选择受到限制；信息不完整本身并不是有限理性的证据。协同推理能力体现为合理衔接成员推理、综合分散证据、发现并修正错误的能力，最终以可独立验证的任务结果评价。

### 2.2 关键科学问题及其重要性

#### 问题一：如何建立具有行为依据的异构智能体博弈模型？

仅用共同任务得分定义收益，不能证明大模型会据此作出有效选择。成员可能无法准确评价自身与同伴的能力，也可能重复计算同源信息的价值；同样的收益差异还可能引起不同模型不同程度的响应。[R21](references.md#r21) [R24](references.md#r24) [R32](references.md#r32) 因此，需要将规范的团队目标与可观察的实际行为联系起来。

本项目研究能力差异、局部信息和任务依赖如何进入成员对联合行动后果的评估，建立连接“行动价值—同伴策略判断—实际选择”的有限理性模型。重点区分行动价值估计偏差与对价值差异的响应程度，检验模型能否预测成员在任务承担、证据请求和推理验证之间的选择。通过具有确定行动后果的可控任务约束模型参数，再考察其在未见任务与成员组合中的预测能力。

这一问题提供博弈分析所需的策略响应依据，使模型能够对实际交互作出可被否证的预测，而不只在事后解释某次协作成功或失败。

#### 问题二：任务分工与信息交互如何影响均衡形成及其推理质量？

个体都依据现有判断作出合理响应，仍可能形成低效协作：某项任务无人承担，两个成员重复完成同一环节，或者原有分工只有通过共同调整才能改善。均衡描述成员策略之间的相互一致性，并不自动保证任务质量最优。共同收益与势博弈研究已经区分了均衡存在和全局效率，本项目进一步研究异构推理能力、任务依赖和信息反馈在其中的具体作用。[R06](references.md#r06) [R52](references.md#r52)

本项目在问题一的基础上，分析一方行动如何改变另一方行动的边际价值，研究成员能力匹配、任务互补或替代关系，以及信息披露对策略响应和均衡选择的共同影响。重点回答：何种条件下能力互补能够形成有效分工；何种判断偏差会使关键推理环节持续缺失；何时需要联合调整职责或信息条件才能改善原有策略组合。任务环节之间的依赖与收益上的策略互补分别定义，避免仅凭角色不同就认定协作有效。[R47](references.md#r47) [R48](references.md#r48)

这一问题将成员行为与系统推理效果联系起来，为判断“当前协作为什么低效、应当调整哪一类策略关系”提供依据。

#### 问题三：如何依据均衡分析形成可执行的协同改进方法？

自然任务中的收益和成员响应只能近似估计，反复协调也会消耗推理预算。因而，即使理想模型存在高质量均衡，仍需研究成员如何在有限交互中到达有用的策略组合，以及模型误差是否会抵消预期收益。

本项目依据前两项研究，设计以预期团队贡献为依据的任务协调、信息披露和策略更新方法。研究何时采用单成员调整，何时需要有限的联合职责调整；分析信息可见范围和更新顺序如何影响有效响应；进一步建立考虑估计误差与协调成本的启用和停止条件。以相同信息、预算和校准数据下的工作流、动态路由及非博弈自适应方法为对照，检验博弈结构是否改善未见条件下的策略预测与任务结果。

三项问题形成“博弈建模与行为辨识—均衡形成与效率分析—协同机制与策略更新”的递进关系，共同服务于异构大模型智能体系统协同推理能力的提升。

### 2.3 国内外研究现状与项目定位

**协作组织已从固定角色扩展到可优化结构与动态分工。** MetaGPT以角色职责和结构化交接组织任务，GPTSwarm将语言智能体及其连接建模为可优化图，AgentNet结合局部路由和经验记忆形成动态任务分配。[R12](references.md#r12) [R53](references.md#r53) [R54](references.md#r54) 这些工作已经能够调整协作方式，因此“从固定流程转向动态协作”不足以构成项目创新。需要进一步研究的是：成员为何对某种分工和信息条件作出特定响应，这些响应如何相互约束，以及由此形成的策略组合为何具有不同效率。

**博弈论已被直接用于大模型协作，项目需要明确进一步研究的对象。** ECON通过信念建模与层级协调研究均衡求解；DICE进一步研究异构量化响应均衡及条件性收敛，并考虑实际更新误差和冻结模型的控制方式。[R34](references.md#r34) [R22](references.md#r22) 量化响应决策聚合则在指定信号结构下研究有限理性与聚合结果之间的关系。[R23](references.md#r23) 因此，采用博弈框架、引入有限理性或分析一般性收敛误差均已有直接基础。本项目将研究重点落在任务分工与信息交互的耦合：用实际行为约束策略响应，分析任务结构和能力差异如何影响均衡质量，并据此形成可检验的协同改进方法。

**有限理性理论提供建模工具，也提出了辨识要求。** Simon的决策理论、量化响应均衡、认知层级及信息处理成本研究，从不同角度刻画决策限制。[R01](references.md#r01) [R03](references.md#r03) [R04](references.md#r04) [R05](references.md#r05) 但过于自由的误差结构会削弱模型的经验内容，参数解释需要依赖跨条件变化和不变性约束。[R31](references.md#r31) [R46](references.md#r46) 本项目以受约束的量化响应为主要候选模型，通过独立价值校准、参数共享与留出干预，检验其解释范围；不将模型自述或拟合参数直接视为内部认知状态。

**共同收益、势博弈与博弈学习为协同设计提供理论基础。** 利益一致博弈明确了成员共享收益函数的结构，势博弈将个体收益变化与整体目标联系起来。[R51](references.md#r51) [R06](references.md#r06) 相关控制与学习研究说明了局部策略调整和均衡选择的分析路径，也表明结论依赖行动、观测及更新方式等条件。[R52](references.md#r52) [R55](references.md#r55) 本项目将这些理论用于有限行动和可验证推理任务，研究收益估计、有限理性响应与有限轮执行的具体影响。已有渐近学习结论不直接构成自然语言交互的有限预算保证。

**信息协作与失效分析为研究分工反馈提供观测依据。** iAgents与MAST分别关注信息不对称和多智能体失效；CoVe、ColMAD和GAVEL探索证据补充、验证与修正；InfoDelphi及相关不确定性方法关注证据组织和可靠信息利用。[R16](references.md#r16) [R17](references.md#r17) [R45](references.md#r45) [R36](references.md#r36) [R43](references.md#r43) [R37](references.md#r37) [R38](references.md#r38) [R40](references.md#r40) 社会学习与信息获取理论进一步说明，重复信息、行动依赖和新增信息价值之间的关系具有明确条件。[R32](references.md#r32) [R33](references.md#r33) [R47](references.md#r47) [R48](references.md#r48) 本项目将证据获取与核验作为分工中的具体行动，分析它们如何影响后续策略；辩论是其中一种交互形式。

### 2.4 研究价值与范围

项目的理论价值在于建立异构成员行为、任务策略依赖和系统推理质量之间的联系，揭示共同目标下有效分工与低效协作的形成条件。方法价值在于将这些条件转化为任务协调与策略更新的依据，使协作方式能够适应成员能力、任务依赖及当前信息状态。

研究聚焦二至四个冻结大模型驱动的智能体、有限轮交互和可验证任务。以给定或由统一前处理产生的有限任务依赖图为基础，研究任务承担、信息交换与推理验证的策略选择；开放式任务分解、任意组织结构搜索和底层模型训练不作为主要研究任务。代码诊断中的定位、修复与测试提供贯穿三项研究的应用场景，任务图可描述环节依赖，但不预先指定每个环节由谁承担。

博弈采用共同收益设定，允许成员因能力、信息和响应规律不同而采取不同策略。此处的合作目标不等同于联盟价值分配意义上的合作博弈；支付激励和多组织利益冲突不纳入主要范围。

## 3. 研究内容、技术路线与验证方案

### 3.1 研究内容及其关联

三项研究使用一致的任务、行动与收益定义。研究内容一给出可检验的博弈模型及异构策略响应；研究内容二据此分析分工、信息交互和均衡质量；研究内容三利用得到支持的条件设计协同机制，并以独立任务检验其效果。

| 研究内容                             | 主要对象                               | 预期产出                           | 与后续研究的联系                   |
| ------------------------------------ | -------------------------------------- | ---------------------------------- | ---------------------------------- |
| 一：有限理性博弈建模与策略响应辨识   | 能力与信息差异、行动价值、同伴策略判断 | 可辨识的响应模型与适用范围         | 为均衡及策略更新提供行为依据       |
| 二：任务分工与信息交互的均衡分析     | 行动依赖、分工形成、均衡效率           | 有效协同条件、低效情形及可观测判据 | 确定需要调整的职责、信息与更新条件 |
| 三：基于均衡分析的协同机制与策略更新 | 任务协调、信息披露、有限轮执行         | 具有误差控制的协同方法             | 用实际推理结果检验整条研究链       |

#### 研究内容一：异构智能体的有限理性博弈建模与策略响应辨识

本部分围绕“成员如何评价自身行动及同伴策略”建立博弈模型，使任务分工与信息交互具有统一的决策表示。

**（1）建立任务依赖与异构能力共同作用的收益模型。** 以有限任务图表示推理环节及其先后依赖，以成员完成各类任务的可靠性、资源消耗及证据利用能力描述异构性。将承担可执行任务、请求或提供证据、检查已有结果及结束当前工作定义为可记录行动，以最终任务质量和总成本构成共同收益。研究不同成员组合完成同一任务时的收益变化，区分能力不足、任务衔接失败和重复投入造成的损失。通过可控任务中的联合行动比较，获得后续行为分析的独立价值参照。

**（2）刻画对行动价值与同伴策略的有限理性响应。** 研究成员如何依据局部证据和同伴工作状态选择任务，重点考察能力估计、信息新增价值和同伴行动预期的偏差。例如，同伴宣称已完成定位，是否使修复成员过早接受结论；同伴已承担一项检查，是否导致必要的互补检查被放弃。采用受约束的量化响应描述价值差异与行动概率之间的关系，分离价值估计偏差和响应敏感性，并通过实际行动、工具结果和任务后果共同检验模型解释。对同伴策略的判断以可检验预测刻画，不将语言化理由视为真实内部推理的直接记录。

**（3）研究响应模型的辨识条件与迁移范围。** 在保持任务答案和基础信息可比的条件下，分别改变成员能力配置、同伴可选任务及信息可见条件，检验不同模型解释能否产生可区分的预测。固定收益尺度与参考行动，优先在同一模型和预算档位内共享参数，以模拟恢复、重复估计和留出干预验证稳定性。对无法独立辨识的价值偏差与选择偏差报告联合效应；对未见任务结构和成员组合检验预测误差，明确哪些规律可以进入后续理论分析。

#### 研究内容二：任务分工与信息交互的均衡分析

本部分使用研究内容一的收益结构与响应模型，研究“成员相互响应后形成何种分工，以及这种分工为何有效或低效”。

**（1）分析任务依赖与能力差异对分工均衡的影响。** 从二成员、少量任务的可枚举模型入手，区分任务收益可分离、任务相互补充和任务重复覆盖等情形，比较不同能力组合下的均衡及团队最优参照。重点分析成员的局部调整是否足以改善分工，何时必须共同变更职责才能补齐关键环节。逐步扩展到三至四成员的有限任务图，研究能力估计误差和响应敏感性如何改变均衡数量、局部稳定性及质量差异，形成与具体任务类对应的条件性结论。

**（2）揭示信息交互与任务选择之间的反馈。** 分析共享原始证据、阶段结论和工作状态分别如何改变成员对同伴策略及任务价值的判断，以及由此产生的任务调整如何改变下一轮可用信息。已有检查与新增检查可能互补，也可能相互替代；提前披露结论可能提供有效线索，也可能使成员高估任务完成程度。通过干预信息条件和指定行动的配对比较，区分信息对答案的直接影响与其通过分工变化产生的影响，并研究这些反馈何时改善证据覆盖、何时阻碍纠错。

**（3）建立均衡性质与协同推理质量之间的联系。** 分别评价策略响应是否相互一致、关键推理环节是否得到可靠完成，以及最终结果是否正确。对理想收益和一致信念条件下的均衡分析，引入行为辨识误差，研究结论对能力估计、信息重复和非精确响应的敏感性。重点形成能够由运行信息和校准数据检查的判据，例如关键任务的预期覆盖不足、单成员调整无效但联合调整有益、信息披露引起错误分工的风险。多轮结论限定在明确状态更新和后续策略的模型中，避免用单阶段稳定性代替整个推理过程的正确性。

#### 研究内容三：基于均衡分析的协同机制与策略更新

本部分将前两项研究转化为可执行的协同方法，研究“如何改变成员的决策条件，使相互响应更有利于共同任务”。

**（1）设计以团队贡献为依据的任务协调方法。** 根据当前任务状态、成员能力及同伴策略，估计改变自身任务对最终团队结果的条件性贡献，形成局部任务建议和策略更新依据。对重复投入和职责空缺，研究单成员调整；对研究内容二识别出的协调困难，研究有限的角色交换或联合职责建议。成员仍依据可用信息形成响应，机制同时记录建议、接受和实际执行，检验设计目标能否转化为行为变化。与仅根据个体能力评分分配任务的方法比较，明确考虑同伴策略的作用。

**（2）联合设计信息披露和更新顺序。** 将信息安排与任务协调一起考虑：在需要承接上游推理时共享关键证据和依赖状态，在需要形成独立检查时延后披露上游结论。根据行动之间的互补或替代关系，研究逐次更新、有限并行及必要的联合调整，减少反复变更职责与相互等待。信息交换的选择依据其对策略判断和任务结果的预期影响，相关性与重复信息的处理需要真实证据支持，不预设“更多共享”或“完全隔离”普遍最优。[R32](references.md#r32) [R42](references.md#r42) [R45](references.md#r45)

**（3）研究有限预算与响应误差下的机制可靠性。** 将收益估计误差、建议执行偏差和协调开销纳入机制评价，限制每个任务状态的策略调整次数，在改进证据不足时保留经过校准的安排。对可控任务研究有限更新次数下的策略残差与质量损失；对自然任务检验相同预算下的任务成功率、遗漏环节和错误接受情况。用不含博弈依赖的自适应控制器、现有图优化与路由方法检验增量价值，区分来自额外数据、额外调用与策略结构建模的收益。

### 3.2 技术路线与关键方法

#### （1）明确博弈要素与实际系统的对应关系

| 博弈要素   | 本项目中的具体定义                                                 | 主要观测依据                     |
| ---------- | ------------------------------------------------------------------ | -------------------------------- |
| 参与者     | 由冻结大模型及局部策略模块构成的智能体                             | 模型版本、工具权限与控制接口     |
| 信息与类型 | 局部证据、任务状态及异构能力；能力由校准数据估计                   | 证据来源、历史执行结果和可见消息 |
| 行动与策略 | 承担可执行任务、交换证据、验证或结束；策略将可见历史映射为行动概率 | 任务选择、消息、调用及实际执行   |
| 收益       | 所有成员共享最终任务质量扣除总资源成本的评价                       | 独立任务评价与完整成本记录       |
| 信念与响应 | 对同伴策略及行动后果的估计，以及据此形成的选择                     | 留出条件下的策略预测与执行分布   |
| 均衡与机制 | 相互一致的策略响应；影响响应的信息、建议与更新规则                 | 策略残差、执行偏差及最终任务质量 |

任务图与成员分工分别表示。统一前处理只给出有限子任务及依赖，所有主要对照使用相同任务图和初始证据。候选行动由前置条件和预定预算额度约束，任务冲突处理规则预先固定并对方法保持一致，避免把冲突仲裁本身变成隐藏的优化器。

#### （2）收益定义、行为辨识与均衡解释

记 $`\tau`$ 为一次完整任务轨迹，$`R(\tau)`$ 为任务质量，$`C(\tau)`$ 为总资源消耗，定义共同收益

```math
u_i(\tau)=U(\tau)=R(\tau)-\eta C(\tau),\qquad i=1,\ldots,n.
```

成本系数 $`\eta`$ 在开发阶段确定并进行敏感性分析；主结果仍按固定预算比较正确率，分别报告质量和成本。共同收益是系统设计的规范目标，模型是否有效响应这一目标由实验判断。测试集答案不进入运行决策，行动价值由校准数据及当前可见反馈估计。[R51](references.md#r51)

在固定决策状态和后续策略的局部模型中，以 $`h_i`$ 表示成员可见历史，$`\pi_{-i}`$ 表示其他成员策略。候选响应模型为

```math
\pi_i(a_i\mid h_i)
\propto \exp\!\left\{\lambda_i
\widehat Q_i(a_i,h_i,\pi_{-i};\theta_i)\right\}.
```

其中 $`\widehat Q_i`$ 描述成员行为所反映的预期团队收益，$`\theta_i`$ 仅保留少量可检验的估计偏差参数；$`\lambda_i`$ 描述对价值差异的响应敏感性。通过独立行动后果估计、固定价值尺度和跨条件参数约束，避免二者相互补偿导致解释不唯一。[R31](references.md#r31) [R46](references.md#r46) 推理投入用实际调用与工具动作记录，接口采样温度不直接等同于 $`\lambda_i`$。

只有在收益评估与模型定义相符、信念与策略一致等条件下，响应固定点才解释为相应的量化响应均衡。[R03](references.md#r03) 保留系统性错误信念或价值偏差时，单独分析行为模型的预测及其固定点，不混称为标准QRE。纯粹执行中央指令而没有策略选择的配置作为集中式基线；使用局部策略模块直接实施概率更新时，明确分析对象是包含该模块的智能体，而非声称底层大模型自然具有指定理性程度。

#### （3）从可枚举博弈分析分工效率与信息反馈

首先对固定任务状态、行动集合和后续处理规则构造有限共同收益博弈。局部证据不同时，以证据类型及其共同先验明确不完全信息结构，策略按成员可见类型定义；共同先验和收益估计的适用性由校准数据检验。先在公共信息情形分析分工依赖，再引入私人证据，分别评价信息差异与响应偏差。二成员情形下，固定其余条件，比较成员分别选择行动 $`a_i,a_i'`$ 和 $`a_j,a_j'`$ 时的收益交叉差分：

```math
\Gamma_{ij}
=U(a_i,a_j)-U(a_i',a_j)-U(a_i,a_j')+U(a_i',a_j').
```

正值表示从 $`a_j'`$ 转向 $`a_j`$ 提高了成员 $`i`$ 从 $`a_i'`$ 转向 $`a_i`$ 的收益，负值表示降低；这一量用于刻画指定行动转换的依赖，不把任意多行动任务笼统归类为全局互补或替代。验证与不验证只是其中一个二元特例。[R47](references.md#r47) [R48](references.md#r48)

在收益表可估计的任务中，枚举行动组合与候选策略，比较最优团队配置、纯策略均衡及量化响应均衡的质量。有限共同收益博弈的势结构是已有基础，研究重点是任务依赖、异构能力和偏差参数如何改变均衡效率与关键环节覆盖，而非重新证明一般存在性。[R06](references.md#r06) 对团队最优参照施加相同的信息、行动与预算约束；访问真实状态的理想策略另作诊断上界。

其次引入信息披露和行动结果更新，研究局部收益与响应如何改变。优先在具有明确任务依赖的有限模型中推导条件或构造反例，再用随机干预检验分工与信息反馈。分别分析均衡存在、局部稳定和有限轮可达性；不能从信息交换后的答案一致推断策略达到均衡，也不能用收敛说明答案正确。

#### （4）将均衡分析转化为有限轮策略更新

形成“估计行动价值与同伴策略—提出局部或联合调整—获得成员响应—执行并更新证据”的循环。调整候选限定为少量任务变更、职责交换和披露安排，使二至四成员情形下的计算与通信开销可控。每项调整都依据条件性团队收益及其不确定性评价，保持未调整部分的后续策略可比。

在每个固定信息状态的协调阶段，以研究内容一得到的响应映射 $`F_i`$ 为基础，首先研究逐次更新：

```math
\pi_i^{k+1}=(1-\alpha_k)\pi_i^k+
\alpha_k F_i(\pi_{-i}^k;h_i),\qquad 0<\alpha_k\leq 1.
```

每步仅更新被选成员，其他成员暂时保持策略；$`\alpha_k`$ 是协调模块的更新步长，与描述成员行为的响应参数分别校准。依据收益依赖和响应误差分析适用步长、更新顺序及有限步残差。当单成员调整无法改善而职责交换具有可靠收益时，进入受限的联合建议阶段，重新评价响应与执行结果；联合建议产生的相关行动不直接赋予独立混合策略QRE解释。

先在已知收益模型中检验上述更新，再引入校准误差、自然语言执行偏差和有限预算。采用对数线性学习作理论参照时，单独说明其联合行动随机过程与渐近结论，不将其平稳分布等同于QRE。[R55](references.md#r55) 理论保证限定在满足所需条件的模型中，真实推理任务通过独立实验检验。

运行时由局部策略模块利用可见任务状态和校准模型生成建议或实施策略更新，大模型负责具体推理与工具使用；建议方式与直接控制方式分别报告。信息披露规则公开且固定可复现，记录未接受建议、执行失败和角色调整成本。策略残差下降只作为过程证据；停止条件同时考虑预期质量改进、预测误差与剩余预算。模型覆盖不足时使用已校准的固定流程，完整计入切换和试探成本。

全程区分运行证据、离线校准标签和独立评测标签。新增检查及候选探索都计费；知道当前答案正确性的策略只用于分析上界。

### 3.3 验证方案

#### （1）任务体系与实验规模

采用“可控博弈辨识—自然推理任务验证”的两层体系。

第一层构建具有确定答案、有限任务图和可记录行动后果的证据整合与逻辑推理任务。通过任务依赖与证据结构形成可分离、互补和重复覆盖等不同情形，再用执行结果检验实际收益关系；不由生成标签直接认定策略互补。先在二成员设置获得可枚举收益与策略比较，再检验三至四成员组合。任务种子与结构分别划分校准、开发和测试集合，避免模板近重复泄漏。[R39](references.md#r39)

第二层采用代码诊断与小规模修复任务，统一提供定位、候选修复、测试和审查等可选工作及依赖，各成员可以承担或调整具体职责。以SWE-bench适用子集及新生成、独立验证的缺陷任务检验能力匹配、推理衔接和纠错效果。公开开发测试可供运行使用，评测测试和参考补丁隔离；任务筛选与失败处理规则预先固定。[R27](references.md#r27)

主实验选择三个模型家族，构造二至四成员的同构、异构与能力配置互换对照，固定版本和解码设置。能力按子任务可靠性、证据利用和错误相关性测量。先导实验确定干预强度、方差与调用成本，正式样本量依据任务级统计功效确定；开发结束后冻结主要比较，避免对全部因素穷举而挤占关键检验资源。

#### （2）科学问题与检验证据

| 检验假设                                         | 关键干预或比较                                 | 主要证据                                     | 未获支持时的处理                           |
| ------------------------------------------------ | ---------------------------------------------- | -------------------------------------------- | ------------------------------------------ |
| H1：实际策略响应能够由受约束的有限理性模型预测   | 改变同伴任务选择、能力配置与信息条件           | 留出行动预测、干预效应及参数稳定性           | 缩减参数，保留可辨识效应和明确预测范围     |
| H2：任务依赖和信息反馈共同影响分工均衡及推理质量 | 配对改变收益依赖、披露和指定任务承担           | 联合行动收益、响应残差、关键环节覆盖及正确性 | 检查能力差异或信息直接效应是否足以解释结果 |
| H3：均衡分析指导的策略更新改善有限预算下的协同   | 与固定分工、图优化、动态路由及同数据控制器比较 | 任务成功率、质量成本曲线及未见结构表现       | 报告无收益区间，分析误差和协调开销         |
| H4：误差处理提高机制在未见组合上的可靠性         | 移除误差惩罚，留出任务结构与成员组合           | 性能退化、建议执行偏差和重新校准成本         | 限定迁移范围，采用任务或成员分组校准       |

对H2实施两阶段随机干预：先随机分配信息条件，再随机指定部分任务承担，分别估计信息的总效应、固定行动条件下的效应及其交互。可控任务由程序落实行动，自然任务记录分配要求与实际执行并以随机分配报告效应。这些比较用于检验作用路径，不能仅凭自然轨迹中的“更多核验对应更高正确率”认定因果关系，也不在缺少额外假设时宣称识别了全部中介效应。

#### （3）比较方法与公平性

**强单模型与独立集成。** 在开发集选择最强成员及推理配置，比较独立求解、自一致性、多次采样加验证、CoVe和无通信异构集成。将团队初始证据并集提供给集中式对照，使用可比工具权限与预算，排除额外信息和额外计算造成的表面协作收益。[R25](references.md#r25) [R26](references.md#r26) [R29](references.md#r29) [R45](references.md#r45)

**工作流、图优化与动态路由。** 比较固定角色流程、固定核验和ColMAD类证据协作，并纳入GPTSwarm、AgentNet代表的结构优化与自适应分工方法。[R12](references.md#r12) [R36](references.md#r36) [R53](references.md#r53) [R54](references.md#r54) 统一任务图的主要比较中，对齐可调整的分工与通信空间，明确受限适配与原方法的区别；完整方法另设系统级比较。结构搜索、经验记忆和开发数据开销单独列明，测试阶段不利用隐藏标签更新记忆。

**现有博弈方法与同数据自适应方法。** 在行动、观测权限和训练条件可对齐的设置中比较ECON、DICE适用实现；训练版与冻结模型版分别报告。[R34](references.md#r34) [R22](references.md#r22) 设置一个使用相同状态、候选调整和校准数据、直接预测团队收益的非博弈控制器，检验策略相互依赖建模是否改善样本利用、未见条件预测或最终结果。不能仅用自适应方法击败固定规则证明博弈方法有效。

代码任务增加Self-Debugging和MapCoder类规划、生成与调试对照，说明从程序生成到仓库修复的接口调整，并保持可见测试一致。[R49](references.md#r49) [R50](references.md#r50)

完整记录输入输出token、工具调用、失败重试、策略估计、协调与端到端时延。异构模型token不直接视为等量计算，另报实际费用或统一硬件时间。离线校准、结构搜索和在线执行分开核算，报告不同任务量下的摊销成本。可复用初始候选的比较保持候选一致，额外生成完整计费。

#### （4）评价指标、消融与统计分析

主要指标为预定预算下的任务正确率或修复成功率，报告相对预先选定强基线的配对差异及95%置信区间。代码任务同时报告错误候选被接受的比例及已接受结果中的错误比例，避免用成员一致性替代正确性。

博弈模型指标包括行动预测的负对数似然、Brier分数、留出干预预测误差，以及可枚举任务中的策略响应残差与均衡质量差。自然任务中的残差若依赖近似收益模型，须同时报告估计误差；残差小不能单独证明真实均衡或高质量结果。

过程指标包括关键任务可靠完成率、重复执行比例、任务切换次数、必要证据覆盖和正确转错误、错误转正确的概率。分别记录“被分配”“被接受”和“实际完成”的任务，检查机制收益是否通过预测的路径发生；来源数量和文本差异不直接替代信息独立性。

消融依次移除同伴策略依赖、异构响应、联合职责调整、信息与分工联动以及误差处理，保持输入、候选空间和数据量可比。除随机划分外，采用整类任务结构和整组成员组合留出，检验模型是否超出校准样本仍具有预测价值。

以任务为统计单位进行配对分析，多轮消息和重复采样作为相关观测处理，使用任务级重采样或分层模型估计区间。预先确定主要假设，探索性比较另行标注并控制多重比较；解析失败、超时及未解决任务纳入主结果。保存版本、提示、任务种子、消息权限、策略建议、实际行动、工具结果和全部成本，支持按任务重放。

### 3.4 预期创新与研究成果

**第一，形成任务分工与信息交互相联系的有限理性博弈模型。** 将异构能力、行动依赖及行为辨识结合，研究实际成员如何响应任务价值与同伴策略变化，给出可辨识条件和跨条件预测范围，使博弈模型具有可验证的行为基础。

**第二，揭示异构能力经由策略交互转化为协同推理能力的条件。** 在明确任务类中研究分工与信息反馈如何影响均衡质量，区分能力互补、局部稳定和任务正确性，形成关于关键环节缺失、低效分工及联合调整必要性的条件性结论。

**第三，形成由均衡分析指导的有限预算协同方法。** 结合任务协调、信息披露与策略更新，研究行为和收益估计误差下的可执行改进，并通过同信息、同预算及同校准数据比较确定博弈结构的实际贡献。

上述为拟研究增量，其成立需由新结论和独立实验支持。一般性均衡存在、势结构、对数线性学习及动态分工本身不作为创新。预期形成行为模型与辨识方法、明确适用条件的理论结论及反例、协同策略更新原型，以及可复现的任务、轨迹和评测规范。

### 3.5 三年实施计划与可行性

| 阶段               | 主要任务                                                 | 阶段产出与验收依据                                   |
| ------------------ | -------------------------------------------------------- | ---------------------------------------------------- |
| 第一年：建模与辨识 | 复现主要基线；构建有限任务图与收益参照；开展策略响应实验 | 可重放数据、受约束响应模型、留出预测及辨识范围       |
| 第二年：均衡与机理 | 分析分工均衡、信息反馈和低效条件；开展随机干预           | 任务类内的理论结论与反例、关键路径证据、机制设计判据 |
| 第三年：机制与验证 | 实现任务协调及策略更新；开展代码任务、迁移和消融比较     | 有限预算协同原型、强基线比较、适用边界与研究论文     |

可行性来自可程序生成的任务、有限成员与行动集合，以及冻结模型和可执行工具带来的实验可控性。先在二成员可枚举情形建立可靠联系，再扩展到有限任务图与代码诊断，避免同时承担开放式任务分解、组织结构搜索和模型训练。

第一年以响应模型的可预测性作为进入复杂分析的依据；第二年围绕得到支持的任务关系形成理论和反例；第三年冻结方法后开展独立评价。调用资源优先用于关键假设、强基线及必要消融，任务量由先导成本和统计功效决定。

以上为方案的技术可行性。申请人的代表性成果、真实先导数据和实际算力条件需逐项对应补充，见[申请完善说明](application-notes.md)。

### 3.6 主要风险与应对

| 风险                           | 对研究的影响               | 应对方案                                             |
| ------------------------------ | -------------------------- | ---------------------------------------------------- |
| 响应参数不可辨识或跨条件不稳定 | 难以支持细粒度行为解释     | 缩减参数，报告可辨识效应，限定模型适用范围           |
| 任务结构不足以解释分工差异     | 原有均衡效率假设不成立     | 比较能力、信息直接效应与策略依赖，保留反例和负结果   |
| 局部均衡分析不能描述多轮任务   | 理论与实际执行存在差距     | 明确后续策略和状态更新，分别报告局部结论与有限轮证据 |
| 建议未被接受或行动执行失败     | 规范机制不能转化为实际响应 | 测量建议、选择与执行差异，分别检验局部控制和建议模式 |
| 收益误差与协调开销抵消改进     | 部分预算区间无协同优势     | 完整核算成本，设置调整阈值与停止条件，保留已校准流程 |
| 任务或模型版本变化导致校准失效 | 迁移结论与复现受限         | 固定版本，留出任务和成员组合，单独报告重新校准成本   |

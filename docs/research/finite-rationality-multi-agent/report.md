# 有限理性下异构大模型智能体的协同决策机理与交互机制设计

基金选题论证与研究方案报告\
版本日期：2026年10月6日\
研究对象：由不同大模型驱动、具有局部信息并共同完成复杂任务的多智能体系统

## 摘要

异构大模型智能体具有不同的知识覆盖、推理能力和行为响应特征，其协同效果不仅取决于模型能力，还取决于交互协议、信息结构与推理资源配置。多轮讨论可能补充证据，也可能放大错误、造成协调振荡或形成低效共识。本项目拟从有限理性博弈视角，研究交互协议和推理预算作用下的智能体行为辨识、个体决策偏差影响群体协同的机理，以及面对行为不确定性的自适应交互机制。

建议以共同收益的团队协作为主要场景，以策略推理受限和交互信息处理偏差为两类研究对象，形成“行为辨识—协同效率与稳定性分析—机制设计”的研究主线。核心创新候选是可干预、可预测的行为模型及其与交互机制的反馈关系，而非简单地将完全理性均衡替换为量化响应均衡。理论研究从有限行动、有限时域的可控协作任务出发，逐步扩展至异构大模型协同编程，并采用同等资源预算下的强单模型和多模型系统作为比较基准。

**关键词：** 有限理性；异构大模型；多智能体协同；量化响应；团队博弈；交互机制；推理资源分配

## 一 选题建议与研究边界

### 推荐题目

**主选题：有限理性下异构大模型智能体的协同决策机理与交互机制设计。**

该题目同时明确研究条件、研究对象和研究目标。“协同决策机理”承接行为辨识与博弈分析，“交互机制设计”承接信息披露和推理资源配置，不预设所有系统都能达到唯一均衡。

“博弈论”可以在技术路线中明确，无须再加入已经较长的题目。青年项目宜选择一个主要干预维度和一个应用场景；面上项目可在同一行为模型下增加联合资源配置和跨模型迁移。具体资助类别、执行年限和申报要求应按拟申报项目确定。

### 研究对象与排除边界

研究对象是多个不同模型驱动的 Agent；同一模型扮演多个角色是必要对照，不作为“模型异构”的充分证据。异构性应通过任务能力、错误相关性、响应敏感度和成本曲线测量。

主要研究共同目标、局部信息下的分布式协同。即使收益一致，智能体的行动也相互依赖，仍可能出现多个协调结果、信息不足和局部决策失配。以团队博弈或协调博弈作为主模型具有合理性；不能仅因存在多个 Agent，就赋予它们未经验证的自利偏好。

跨机构的支付、契约、虚报和激励相容仅作为后续扩展。投机解码中的草稿模型与验证模型协同也不直接等同于自主 Agent 的策略协同；现有训练和推理设施可支持实验，但不能据此宣称已完成本项目的前期理论验证。

## 二 立项依据与已有研究

### 有限理性具有理论基础

Simon 将认知和计算限制纳入理性选择研究。[R01](references.md#r01) 纳什均衡提供相互最佳响应的基准，但均衡存在并不保证现实交互过程能够到达该均衡。[R02](references.md#r02) 量化响应均衡以概率响应刻画非精确优化；认知层级模型刻画对他人策略的有限递归推理。[R03](references.md#r03) [R04](references.md#r04) 信息处理成本模型进一步将效用收益与计算成本结合。[R05](references.md#r05)

因此，不能将“传统博弈论只考虑完全理性”作为立项依据。本项目需要解决的是：既有行为模型在自然语言接口、异构模型和可调推理预算下如何辨识，以及这些行为条件对协作机制有什么影响。势博弈和信息设计可分别提供协调结构与信息披露的分析工具，但其应用必须验证相应假设。[R06](references.md#r06) [R07](references.md#r07)

### 多智能体框架提供实现基础

多智能体辩论通过多轮提议与修正改善部分推理和事实性任务，AutoGen 和 MetaGPT 分别提供可编程交互与角色流程组织方案。[R10](references.md#r10) [R11](references.md#r11) [R12](references.md#r12) 协同机制综述和博弈论综述已从组织结构、策略、收益和信息等角度梳理相关研究。[R13](references.md#r13) [R14](references.md#r14) [R15](references.md#r15)

这些工作为实验系统提供基础。基金研究仍需给出框架之外的可检验命题，说明某种交互规则在什么条件下有效、失效和可迁移。

### 协同失效需要区分来源

iAgents 将信息不对称作为协作任务的重要条件。[R16](references.md#r16) MAST 从系统设计、智能体间失配和任务验证等方面组织失败模式，说明不能把所有失败都归因于单个模型能力。[R17](references.md#r17) 对多智能体辩论的系统评估强调强单模型基线和模型异构性的作用，其结果受评测模型与任务范围限制。[R18](references.md#r18)

迎合研究显示，大模型可能受到外部立场影响；多 Agent 辩论中的相关工作进一步讨论了同伴迎合与过早共识。[R19](references.md#r19) [R30](references.md#r30) 这些现象支持设置身份、顺序和证据内容的干预实验，但不意味着所有意见变化都是迎合：合理吸收新证据也会导致观点改变。

贡献分配与合作激励已有 Shapley-Coop 等研究。[R20](references.md#r20) 对零成本信息共享任务的研究进一步区分了能力限制与合作行为限制。[R21](references.md#r21) 本项目因此不把缺少合作直接解释为自利，而将目标理解、收益响应和执行能力分别测量。

### 最接近工作的比较

有限理性均衡学习已在平均场博弈和风险敏感马尔可夫博弈中得到研究。[R08](references.md#r08) [R09](references.md#r09) DICE 预印本将异构量化响应均衡用于大模型协同，并在单调性等条件下分析稳定性。[R22](references.md#r22) Decision Aggregation under Quantal Response 在条件独立同分布信号等假设下研究决策聚合。[R23](references.md#r23) 基于显式经济偏好的微调也被用于改变大模型策略行为。[R24](references.md#r24)

| 研究线索           | 已有研究的切入点               | 本项目需验证的区分点                           |
| ------------------ | ------------------------------ | ---------------------------------------------- |
| 有限理性均衡学习   | 在指定响应模型下定义与计算均衡 | 响应模型是否能由异构大模型的干预数据辨识       |
| DICE               | 异构正则化均衡与协调稳定性     | 协议和资源如何改变实际行为，以及辨识误差的影响 |
| 量化响应决策聚合   | 特定信号条件下的聚合规则       | 交互引起的信号相关性及资源干预如何影响协同     |
| 协同失效与迎合分析 | 失败分类及行为现象             | 可区分不同解释的实验，以及可预测的机制分析     |
| 多 Agent 激励      | 贡献分配与合作收益             | 共同收益条件下，有限决策能力仍造成的协调损失   |

上述区分点是拟研究方向，不能据此直接宣称“首次提出”或“现有研究均未考虑”。详细阅读与复现应进一步检查既有论文的实验控制、参数估计和理论假设；文献比较见 [literature-matrix.md](literature-matrix.md)。

## 三 核心概念与研究假设

### 有限理性的操作性定义

在任务目标、可用信息和行动集合明确时，由推理资源限制或交互信息处理偏差引起的、可重复且可预测的决策偏离，作为本项目研究的有限理性行为。比较基准必须具有同等信息和可行行动，避免用全信息最优解评价局部信息智能体。

| 现象                                 | 首要解释             | 识别措施                                 |
| ------------------------------------ | -------------------- | ---------------------------------------- |
| 缺少关键事实而失败                   | 信息不足             | 向对照组补足信息，保持协议与预算一致     |
| 知道事实但无法完成任务               | 能力或计算限制       | 使用独立求解对照，并逐级改变预算         |
| 在规则重述后表现改善                 | 规则理解或表征限制   | 设置结构化规则与自然语言规则对照         |
| 保持建议内容不变，改变身份后行动变化 | 身份相关响应         | 随机化来源标签，估计效应及置信区间       |
| 保持信息和效用不变，增加互动反而失败 | 协调或交互处理问题   | 使用无交互、延迟披露和独立验证对照       |
| 不按规定效用行事                     | 目标未内化或响应不足 | 先验证收益敏感性，不直接判定为恶意或自利 |

主要考虑两类行为：策略推理受限、交互信息处理偏差。风险偏好和社会偏好不作为主参数，除非先导实验显示它们对任务具有不可忽略的解释力。

### 可证伪的研究假设

**假设 H1：行为响应具有条件依赖性。** 同一模型对行动价值的敏感度随任务、预算与交互协议变化。检验标准是条件模型能否在留出任务和协议上优于固定参数模型；如果改善不稳定，应接受更简单模型。

**假设 H2：交互对偏差具有放大或抑制作用。** 控制信息内容后，身份、顺序和消息可见性仍可能改变行动；该效应应通过随机干预估计。若效应可由新增证据完全解释，则不将其记为交互偏差。

**假设 H3：预算增加对团队收益可能非单调。** 在给定协议下增加一个智能体的推理投入，可能改变分工和对队友的响应。该非单调性是待验证假设，不能作为既定事实；若不出现，则转向研究边际收益差异。

**假设 H4：考虑行为不确定性的机制具有迁移优势。** 当模型或任务变化时，使用响应置信集合的机制有望减少性能退化。必须与同预算的非博弈自适应控制器比较，避免将一般自适应收益归为博弈模型贡献。

## 四 科学问题与研究内容

### 科学问题一 有限理性行为的可辨识性

如何从可观测行动、工具执行及任务结果中，区分价值估计误差、选择随机性和对他人策略的判断偏差？自然语言协议变化后，模型参数是否仍有可比较的含义？

研究内容包括构造可控分工与协同验证环境、设计信息和资源的交叉干预、比较量化响应与认知层级等候选模型，并研究参数可辨识条件。在数据不足时输出参数区间或可观测等价类，而不是强行报告唯一“理性分数”。

预期形成可复现的行为辨识方法、模型选择准则和跨任务预测结果。自然语言解释仅作为辅助记录，不把模型声称的推理步骤当作真实内部决策过程的证据。

### 科学问题二 个体行为与群体协同的耦合机理

局部决策偏差如何经由信息依赖和交互顺序影响团队效率？什么条件下会形成重复劳动、验证遗漏、错误传播或协调振荡？模型异质性什么时候提供互补，什么时候增加协调成本？

研究内容包括有限行动团队博弈建模、响应映射敏感性分析、局部稳定性与性能损失分析，以及模型和任务变化下的跟踪误差分析。均衡存在、算法收敛、局部稳定与任务正确率分别定义和评价。

预期给出适用于明确任务类的充分条件、反例及诊断指标。一般博弈中不承诺全局唯一均衡，也不承诺最优协同必然可达。

### 科学问题三 面向行为不确定性的交互机制设计

当机制改变行为、行为变化又改变机制效果时，如何联合选择信息披露和推理资源，使任务收益在预算约束下稳定提升？辨识误差、队友更换或分布变化时，机制还能维持怎样的性能？

研究内容包括协议条件化行为估计、有限协议库中的鲁棒选择、推理预算配置、变化检测和保守回退。青年项目宜固定一种干预为主，另一种仅作为消融；面上项目再联合优化。

预期形成带有适用条件与可观察诊断的自适应机制，并通过跨任务、跨模型组合与计算预算曲线检验其收益。

## 五 建模框架与技术路线

### 从可控任务到动态协作

设智能体集合为 $`N=\{1,\ldots,n\}`$，任务状态为 $`s_t`$，局部观测为 $`o_{i,t}`$，交互历史为 $`h_{i,t}`$，行动为 $`a_{i,t}`$。机制 $`m_t`$ 决定发言顺序、可见消息、验证要求和停止规则，预算 $`b_{i,t}`$ 决定可用推理资源。有限行动可采用“独立验证、请求证据、执行子任务、移交、提交”等语义动作；自由文本作为动作的参数或证据，不一开始就对无限文本空间求均衡。

主要任务使用共同外部收益 $`R(s_t,\mathbf a_t)`$，并计入系统计算、通信和失败代价。该收益由任务完成标准定义，不等于模型天然内化的效用。需要通过收益变化实验验证智能体是否对该目标有稳定响应；不满足时，将其视为经验行为策略，并收窄均衡解释。

一个基本行为模型为：

```math
\pi_i(a\mid h_i,m,b_i)=
\frac{\exp\{\lambda_i(h_i,m,b_i)\widehat Q_i(a\mid h_i,m,b_i)\}}
{\sum_{a'\in A_i}\exp\{\lambda_i(h_i,m,b_i)\widehat Q_i(a'\mid h_i,m,b_i)\}}.
```

$`\widehat Q_i`$ 是在局部信息和队友行为判断下的行动价值估计，$`\lambda_i`$ 是选择对价值差异的敏感度。模型应与标准量化响应、认知层级以及不含博弈结构的预测模型比较。[R03](references.md#r03) [R04](references.md#r04)

这里存在尺度混淆：若同时将 $`\widehat Q_i`$ 乘以常数、将 $`\lambda_i`$ 除以该常数，策略不变。因此先在可控任务中固定收益尺度和参考行动，分别干预信息与预算，再讨论参数辨识。价值估计误差和选择随机性无法区分时，应报告预测分布或等价类。采样温度是生成接口参数，不直接等于 $`1/\lambda_i`$。

### 建立响应映射并分析稳定性

将一轮交互后的策略分布写为 $`\boldsymbol\pi^{t+1}=F_{m,b,\theta}(\boldsymbol\pi^t)`$，其中 $`\theta`$ 表示待估行为参数。固定点只是该响应模型下的行为一致状态；只有在相应信念一致、响应假设成立时，才能称为所定义的博弈均衡。

以下给出拟采用的分析工具及边界，均不作为项目已经取得的成果：

1. 对有限行动、连续响应的模型，可考察固定点存在条件。存在性不推出唯一性或可达性。
2. 若在不变区域内验证 $`F`$ 是压缩映射，可利用压缩映射结论获得该区域内的唯一固定点和迭代收敛。该充分条件可能较强，需报告不满足条件的实例。
3. 对可微响应映射，研究固定点附近雅可比矩阵的谱半径；小于一可作为局部稳定分析的条件。有限样本估计的谱半径属于诊断量，不等于严格证明。
4. 在两个响应映射满足共同压缩常数 $`L<1`$、且一致误差不超过 $`\varepsilon`$ 时，可推出固定点距离上界 $`\varepsilon/(1-L)`$。这是标准扰动分析起点；项目贡献应是把 $`L`$ 与 $`\varepsilon`$ 联系到可测行为和机制变量，并检验这些条件。

理论效率比较采用同信息、同资源和同可行机制类的基准。低效但稳定的固定点、准确但不稳定的迭代轨迹均需单独讨论。任务持续变化时，以跟踪误差或动态遗憾为目标，不要求全程收敛到固定策略；动态遗憾分析必须限制环境变化量等条件。

### 将协议条件化行为纳入机制设计

设 $`\mathcal M`$ 为可实现的协议库，$`\Theta_t`$ 为行为响应模型的置信集合，$`J`$ 为含成本的任务收益。可采用以下设计原型：

```math
\max_{m\in\mathcal M,\,\mathbf b}\ \min_{\theta\in\Theta_t}
J\bigl(m,\mathbf b;\theta(m,\mathbf b)\bigr),
\qquad
\sum_i c_i(b_i)+c_{\rm comm}(m)+c_{\rm coord}(m)\leq B.
```

该表达强调响应对协议与预算的依赖。$`\Theta_t`$ 应覆盖候选协议上的响应函数，而非只覆盖原协议的一组参数；超出实验支持范围时扩大不确定性，不外推“精确最优协议”。实际求解可采用有限协议枚举、上下文决策和保守在线更新，无须一开始求解大规模连续双层优化。

建议的有限协议库包括：先独立决策后披露、证据优先披露、按需请求验证、限制重复消息、基于外部验证结果停止。身份匿名化作为实验处理和候选机制，不先验假设其一定有益。资源分配以可测预算档位为主，避免把闭源接口的内部推理能力视为完全可控。

执行流程为：

1. 在校准任务上采集信息、预算与协议的干预数据，估计行为响应及不确定性。
2. 根据任务结构和可用预算，选择具有数据支持的交互协议与资源配置。
3. 记录行动、消息可见范围、工具结果与全部开销，执行有限轮协作。
4. 使用外部可验证反馈更新估计；对异常变化触发重新校准或回退。
5. 在独立测试集上报告任务表现、行为预测误差和预算曲线。

信息设计提供研究“披露什么、何时披露”的基础，但其收益与信念假设不能未经验证就移植到 LLM。[R07](references.md#r07) 本项目的信息披露控制仅作用于任务证据与协作流程，不以虚构事实提升说服效果。

## 六 实验设计与评价标准

### 两层实验体系

第一层采用程序生成的可控任务。分工任务包含互补子任务和明确失败条件；协同验证任务包含可控错误与隐藏测试；信息拼接任务使每个 Agent 仅掌握部分约束。通过任务种子和同构变换生成训练、校准、测试集合，减少记忆和模板泄漏。

第二层以协同编程为主要应用：实现者、测试者、审查者共同处理缺陷修复，使用执行结果和隐藏测试评价。SWE-bench 可提供真实软件任务参照，AgentBench 可作为交互评测的补充来源，但两者都不能直接替代多 Agent 因果识别实验。[R27](references.md#r27) [R28](references.md#r28)

主实验先使用两个至四个 Agent，选择至少三个模型家族，并测量各模型独立能力、错误相关性和成本。具体模型版本在实验启动时冻结。扩大团队规模作为压力测试，不把增加成员数量本身作为创新。

### 核心实验与干预

| 实验         | 操纵变量                       | 固定或配对条件                 | 主要观测                           |
| ------------ | ------------------------------ | ------------------------------ | ---------------------------------- |
| 行为辨识     | 预算档位、行动价值差、任务难度 | 信息可见性、模型版本、解码设置 | 响应分布预测、参数可辨识性         |
| 同伴影响     | 建议身份、顺序、措辞           | 建议的事实内容、任务与预算     | 采纳变化、正确转错误率、正确纠错率 |
| 信息不足对照 | 局部或完整信息                 | 任务、协议、模型组合           | 信息约束损失与决策损失的区别       |
| 协同动态     | 信息披露时点、交互轮数         | 团队组成和总预算               | 验证遗漏、动作振荡、收益变化       |
| 预算分配     | 均分、按能力分配、行为模型分配 | 总成本上限和可用工具           | 质量成本前沿、边际收益             |
| 迁移鲁棒性   | 更换队友、难度或协议表达       | 不使用测试标签重新调参         | 性能退化、恢复开销、预测校准       |

采用分阶段设计控制实验规模：先用小样本筛除无效干预，再对主假设做预先固定的验证实验。不要对所有模型、预算、协议和任务做无目的全组合。

### 必要比较基线

强单模型基线包括直接求解、自一致性、多次采样加验证以及自我修正。自一致性、重复采样和测试时计算研究表明额外推理资源本身就能带来收益，因此必须计入这些比较。[R25](references.md#r25) [R26](references.md#r26) [R29](references.md#r29)

多 Agent 基线包括同构固定流程、异构固定流程、无通信独立集成、延迟披露协议，以及静态参数的有限理性机制。在条件匹配时复现最接近的均衡协同方法。另设置同等观测与预算下的非博弈自适应控制器，以识别博弈结构建模的增量贡献。

所有方法共享允许使用的工具、检索资料和验证权限。协调器、消息压缩器、验证器、失败重试和校准的成本全部记录。跨模型 token 数不能直接视作相同计算量；分别报告费用口径、硬件时间、端到端时延及可测计算量。离线校准成本与在线执行成本分别列示，并报告部署任务量变化时的摊销成本。

### 指标和统计方法

- **任务质量：** 成功率、隐藏测试通过率、缺陷发现率及未发现错误的提交率。
- **协同收益：** 同预算下相对预先选定的强单模型基线的配对差异，以及相对无通信异构集成的增量。
- **行为预测：** 留出集负对数似然、Brier 分数和校准误差。模型自报置信度须经外部结果校准。
- **交互失效：** 验证遗漏、无新增证据的重复动作、正确转错误和错误转正确的频率；指标定义在评测前固定。
- **动态稳定性：** 策略分布变化、动作切换和恢复时间，避免用文本相似度等同于均衡收敛。
- **鲁棒性：** 未见模型组合和任务上的质量变化、重新校准样本量、额外开销。

按任务进行配对，使用多次独立运行报告均值、置信区间和效应量。对同一任务的多轮行动使用分层分析或任务级重采样，不把相关回合当成独立样本。主指标和主要比较预先固定；探索性比较明确标注并控制多重检验。样本量由先导实验估计方差后确定，不在没有依据时承诺固定提升百分比。

系统日志保留模型标识、权重版本、提示模板哈希、采样参数、随机种子、预算、消息可见范围和工具调用。记录实际执行行动及外部结果，不依靠模型生成的理由独立判断因果机制。

## 七 创新候选与成立条件

| 创新候选                       | 与常规做法的区别                 | 成立所需证据                         | 不足以支撑创新的情形                 |
| ------------------------------ | -------------------------------- | ------------------------------------ | ------------------------------------ |
| 可干预的有限理性行为辨识       | 对行为来源作区分，并预测未见条件 | 可辨识分析、随机干预和外部预测       | 只拟合训练集，或给模型任意理性分数   |
| 协议与资源作用下的行为耦合分析 | 将机制对行为的影响纳入协同动态   | 可验证假设、充分条件或反例           | 仅增加状态相关参数或复用既有收敛证明 |
| 面向响应误差的鲁棒交互机制     | 在行为不确定时选择可执行协议     | 与非博弈控制器、静态有限理性机制比较 | 收益完全来自更多调用或更强协调模型   |

三项创新应共同服务一个问题：交互和资源如何影响有限理性行为，以及由此产生的协同效率变化。不宜分别堆叠博弈、因果推断、强化学习和图优化，而缺少共同可观测变量。

## 八 实施计划与可行性

以下按三个阶段组织，可映射至实际项目执行期，不作为特定基金年限要求。

| 阶段     | 主要工作                         | 可验收产出                       | 阶段决策                       |
| -------- | -------------------------------- | -------------------------------- | ------------------------------ |
| 第一阶段 | 可控环境、行为干预、候选模型比较 | 数据规范、先导实验、行为预测基线 | 响应模型无预测优势时调整假设   |
| 第二阶段 | 失效机理、稳定条件、静态机制     | 理论命题与反例、机制原型、消融   | 先确认条件适用，再扩展动态场景 |
| 第三阶段 | 自适应机制、模型迁移、真实任务   | 预算匹配实验、开源评测协议、论文 | 报告适用边界和失败实例         |

前期基础应优先补充三类证据：同等预算下的协同退化实例；保持事实内容不变的协议干预结果；行为模型对留出任务的预测优势。这些证据可以直接支撑立项必要性和技术可行性。

现有大模型训练、推理服务和实验记录设施可用于模型接入、资源测量与复现。尚未测得的群体收益、稳定性或行为规律不写成已有成果。主方案优先采用冻结模型，避免同时承担大模型训练和复杂机制学习的双重成本；行为微调作为后续扩展，并单独计算训练开销。

## 九 风险与替代路线

| 风险                       | 可能影响             | 替代路线                                             |
| -------------------------- | -------------------- | ---------------------------------------------------- |
| 量化响应拟合或外推较差     | 理论行为假设缺乏支撑 | 比较认知层级、半参数响应或分布集合，收窄均衡主张     |
| 价值估计与选择敏感度不可分 | 参数解释不可靠       | 固定收益尺度，增加诊断任务，报告等价类或预测区间     |
| 同伴影响可被信息质量解释   | 有限理性解释不成立   | 接受该结果，转向信息结构与预算耦合                   |
| 理论稳定条件过强           | 覆盖真实任务不足     | 区分可证明子类与经验适用范围，提供反例               |
| 同等预算下多 Agent 无优势  | 方法价值不足         | 研究协同启用与停止边界，允许回退强单模型             |
| 在线校准成本过高           | 实际部署不经济       | 使用小协议库、分层参数共享、离线校准和摊销分析       |
| API 或模型更新             | 复现和迁移困难       | 固定本地权重或记录接口版本，增加版本变化测试         |
| 最新研究覆盖预期创新       | 选题差异不足         | 以行为辨识与可测误差为主线继续收窄，不仅更换算法名称 |

## 十 可用于申请书的凝练表述

### 总体目标

面向异构大模型智能体协同决策中行为响应不稳定和交互收益难预测的问题，建立考虑推理资源与交互信息影响的有限理性行为模型，揭示个体决策偏差对群体协同效率与稳定性的作用机理，设计面向行为不确定性的自适应交互机制，并在可控协作环境与多模型协同编程任务中验证其有效性和适用边界。

### 关键科学问题

1. 在信息、偏好和计算因素相互混杂的情况下，如何辨识异构大模型智能体的有限理性行为，并预测其对协议与预算变化的响应？
2. 个体行为响应如何通过交互结构影响群体协同效率与稳定性，协同增益和协同失效分别在什么条件下形成？
3. 当交互机制改变行为响应、且响应模型存在误差时，如何实现预算约束下可迁移的协同机制设计？

### 摘要草案

异构大模型智能体通过分工与交互完成复杂任务，其协同效果受到个体推理能力、局部信息和行为响应差异的共同影响。现有协作流程难以预测协议与推理预算变化引起的群体行为，亟需建立连接个体有限理性与系统协同效能的分析方法。本项目围绕有限理性下异构大模型智能体的协同决策，研究可控信息与资源干预下的行为辨识，分析决策偏差经由交互传播影响协同效率与稳定性的条件，设计考虑响应模型误差的自适应信息交互与资源配置机制。项目将结合有限理性博弈、统计辨识和鲁棒优化，在可控协作任务与真实软件任务中开展同等预算验证，预期形成可检验的行为模型、具有明确假设的协同机理分析及可复现的交互机制，为多大模型智能体系统的可靠协同提供理论与方法支撑。

# 异构大模型智能体系统的有限理性博弈与协同机制研究

基金研究方案报告\
版本日期：2026年10月6日

## 1. 摘要

本项目旨在建立一套面向异构大模型智能体系统的协同方法，使系统能够根据任务特点、成员能力和可用预算，决定如何分工、何时交换信息、由谁进行验证以及何时结束协作，实现在相同资源投入下更可靠地完成复杂任务。不同大模型具有互补能力，但在共同工作时，也可能因误判同伴建议、遗漏验证职责或反复修改正确结果而降低整体表现。项目以有限理性博弈为分析工具，按照“识别个体行为—解释团队表现—改进协作方式”的递进关系开展研究。首先，通过改变信息、交互规则和推理预算，识别智能体何时容易出错、何时能够有效利用同伴信息；其次，将个体行为模型引入团队交互过程，研究错误如何传播或被纠正，明确协作有效与失效的条件；最后，依据上述规律，设计能够调整信息交换、交叉验证和资源分配的协同机制，并利用外部任务结果持续校准。项目将在可控协作任务和协同编程场景中，与同预算的强单模型及固定协作流程比较，检验任务成功率、错误遗漏和总成本，形成行为模型、协作规律与机制原型，为异构大模型智能体系统的可靠、高效运行提供支撑。

**关键词：** 异构大模型；智能体系统；有限理性博弈；行为辨识；协同机制

## 2. 拟解决的问题及其重要性

### 2.1 研究背景与总体目标

本项目研究由不同大模型驱动、基于局部信息共同完成任务的智能体系统。模型之间的差异包括知识覆盖、推理能力、验证能力和使用成本。这些差异为能力互补提供了可能，也使成员之间的理解和配合更加复杂。已有协同失效分析与辩论评测表明，系统表现需要结合个体能力、交互方式和资源投入共同评价。[R17](references.md#r17) [R18](references.md#r18)

以协同编程为例，实现智能体生成修改方案，测试智能体检查程序行为，审查智能体分析潜在缺陷。如果测试智能体因信任实现者的解释而省略独立验证，错误就可能进入最终结果；如果多个成员反复检查同一部分代码，则会消耗预算而遗漏其他问题。研究需要回答的实际问题是：怎样组织这些成员，才能使各自的能力转化为可靠的任务结果？

**项目的最终目标是形成一套有行为依据、能够随任务和成员变化调整的协同方法，在给定总预算下提高复杂任务的完成质量，并减少重复执行、验证遗漏和错误传播。** 系统需要作出四类具体决策：由谁承担任务与验证、哪些信息需要共享、推理资源如何分配，以及何时继续或结束协作。协同收益将通过同预算比较检验；对不适合多人协作的任务，机制应能选择独立执行。

本项目以共同收益的团队博弈为基本框架。这里的“博弈”用于描述行动之间的相互影响：一个成员是否需要验证，取决于其他成员是否已经验证以及验证是否可靠。“有限理性”指智能体受推理资源和信息处理能力限制，难以始终作出最有利于任务的判断。博弈分析据此研究相互响应的规律，并为交互规则提供依据；最终效果由任务质量和资源成本评价。

### 2.2 拟解决的关键科学问题

#### 问题一 个体决策偏差的来源与预测

相似的错误可能具有不同来源。例如，测试智能体漏检缺陷，可能是缺少代码信息、推理预算不足，也可能是过度依赖其他成员的判断。不同原因需要不同的改进方法。

本项目拟解决的核心问题是：**如何区分智能体出错的主要原因，并预测改变信息、交互方式或预算后，其决策会如何变化？** 通过保持任务条件可比、分别改变关键因素，研究哪些行为能够由稳定规律解释，以及这些规律能否用于尚未见过的任务和成员组合。

该问题为后续研究提供可信的个体行为模型。只有明确补充信息、增加计算或改变交互分别会产生什么作用，才能解释团队失效，并选择有效的改进措施。

#### 问题二 个体行为影响团队表现的作用规律

智能体单独完成任务时的能力，不能充分说明其加入团队后的贡献。同一条建议可能帮助其他成员纠错，也可能使多个成员同时接受错误结论；相同的验证能力，在不同分工和信息顺序下也可能产生不同结果。

本项目拟解决的核心问题是：**个体判断如何在交互中被放大或纠正，什么条件下能力互补能够超过协调带来的损失？** 基于问题一得到的行为模型，分析信息传递、任务依赖和行动顺序，研究团队何时能形成可靠分工，何时会出现重复执行、验证遗漏或反复改变决策。

该问题将个体行为与整体结果联系起来，为选择交互规则提供依据。其中，行为趋于稳定与结果正确分别评价：成员持续保持一致，仍可能共同接受错误结论。

#### 问题三 有限预算下协同规则的选择与调整

明确协作规律后，仍需将其转化为可执行的规则。不同任务需要不同程度的讨论与验证；成员更换后，原有规则的效果也可能变化，而重新了解成员行为需要额外成本。

本项目拟解决的核心问题是：**如何利用行为预测和协作规律，在有限预算下选择分工、信息交换与验证方式，并在预测不准或环境变化时及时调整？** 研究预测可信程度、预期任务收益与执行成本之间的关系，形成规则选择、结果反馈和重新校准的方法。

该问题将前两项研究转化为系统能力，使协作方式具有可解释的选择依据，并明确继续交互、增加验证或停止协作的条件。三项问题依次回答“成员会怎样行动”“这些行动如何影响团队”“如何据此改善团队表现”。

### 2.3 国内外研究现状与研究定位

**有限理性博弈提供行为建模基础。** Simon 将认知与计算限制纳入决策研究；纳什均衡为策略相互响应提供基准。[R01](references.md#r01) [R02](references.md#r02) 量化响应均衡以概率选择刻画非精确优化，认知层级模型描述对他人策略的有限递归推理，信息处理成本模型联系决策收益与计算代价。[R03](references.md#r03) [R04](references.md#r04) [R05](references.md#r05) 势博弈与信息设计分别提供协调结构和信息披露的分析方法。[R06](references.md#r06) [R07](references.md#r07) 这些理论为本项目提供工具，其在自然语言交互与可调推理预算下的行为假设需要通过实验检验。

**多智能体方法形成了多样的协作组织方式。** 多智能体辩论、AutoGen 和 MetaGPT 分别探索迭代修正、可编程交互与角色流程组织。[R10](references.md#r10) [R11](references.md#r11) [R12](references.md#r12) 相关综述从组织结构、信息交互及博弈建模等角度梳理了研究进展。[R13](references.md#r13) [R14](references.md#r14) [R15](references.md#r15) 本项目在此基础上，重点分析协作规则产生效益的行为条件与适用边界。

**协同失效研究揭示了行为来源的复杂性。** iAgents 关注信息不对称；MAST 从系统设计、智能体间失配与任务验证等方面归纳失败模式；辩论评测强调强单模型基线和模型异构性的作用。[R16](references.md#r16) [R17](references.md#r17) [R18](references.md#r18) 迎合研究及多智能体辩论分析进一步提示同伴立场与过早共识的影响。[R19](references.md#r19) [R30](references.md#r30) Shapley-Coop 探索贡献分配与合作激励，零成本信息共享研究则区分能力限制与合作行为限制。[R20](references.md#r20) [R21](references.md#r21) 上述工作支持开展因素分离实验，以辨别信息增益、决策偏差与协调损失。

**有限理性与大模型协作的结合已有直接研究。** 有限理性均衡学习已用于平均场博弈和风险敏感马尔可夫博弈。[R08](references.md#r08) [R09](references.md#r09) DICE 预印本将异构量化响应均衡用于大模型协同，并在单调性等条件下分析稳定性；量化响应决策聚合研究则依赖条件独立同分布信号等假设。[R22](references.md#r22) [R23](references.md#r23) 显式经济偏好微调也被用于调整大模型的策略行为。[R24](references.md#r24)

本项目聚焦上述研究之间的三个联系：**从受控数据辨识行为响应，从响应耦合分析协同机理，从辨识误差设计稳健机制。** 与主要相关工作的比较如下。

| 研究方向           | 已有研究重点                   | 本项目研究重点                       |
| ------------------ | ------------------------------ | ------------------------------------ |
| 有限理性均衡学习   | 指定响应模型下的均衡计算       | 响应模型的实验辨识与预测检验         |

### 2.4 研究意义与范围

理论上，研究有限理性行为与协同动态的联系，建立具有明确假设和可检验条件的稳定性与效率分析方法。方法上，将信息交互、推理预算及行为估计误差纳入统一设计框架。应用上，面向协同编程形成可复用的行为诊断、机制选择与成本评价方法。

研究聚焦共同目标、有限成员、可测预算和可验证结果的协作任务，以冻结模型为主要实验对象。通过同构与异构团队对照，区分模型差异和角色分工的作用。

## 3. 研究内容、技术路线与验证方案

### 3.1 研究内容及其递进关系

围绕总体目标，项目依次研究个体行为、团队交互和协同决策。研究内容一提供“在什么条件下，成员会怎样行动”的预测；研究内容二利用这些预测解释团队表现，提出交互规则的选择依据；研究内容三将上述依据转化为可执行方法，再用任务结果检验并更新前两项研究。

| 研究内容                  | 主要输入                         | 形成的结果                           | 与后续研究的关系                 |
| ------------------------- | -------------------------------- | ------------------------------------ | -------------------------------- |
| 一 个体行为识别与预测     | 任务、成员、信息和预算的对照实验 | 行为预测模型及其可信范围             | 为团队分析提供实际行为依据       |
| 二 团队交互规律与协作条件 | 行为模型、任务依赖和候选交互规则 | 错误传播规律、有效协作条件和失效诊断 | 为机制选择提供规则依据与风险约束 |
| 三 协同规则设计与动态调整 | 行为预测、协作条件及剩余预算     | 可调整的协同机制与系统原型           | 通过外部结果检验并修正模型和规则 |

#### 研究内容一 个体行为识别与预测

本部分研究智能体在协作中如何作出判断，重点识别导致错误决策的可观测因素，建立能够支持后续团队分析的有限理性行为模型。

**（1）设计能够区分错误来源的对照任务。** 构建分工、信息整合和交叉验证任务，使任务目标、可用信息和结果判断标准明确。围绕同一任务分别补充事实、增加推理预算或改变同伴消息的呈现方式，并设置独立求解对照。例如，对同一处代码缺陷，比较测试智能体独立检查、先阅读实现者解释、阅读解释后再获得测试证据三种条件下的行为，以区分能力不足、信息不足和交互影响。通过多因素组合实验，进一步检验这些因素是否相互作用。

**（2）建立面向协作决策的行为预测模型。** 将验证、请求证据、接受建议、修改方案和提交结果等行为转化为可分析的行动，记录各行动的发生概率、结果质量与资源消耗。采用量化响应等有限理性模型描述智能体对行动收益和同伴判断的反应，并与更简单的统计预测方法比较。模型重点预测某类条件下的行为和错误风险，例如增加一档预算能否改善独立验证、何种证据更可能促使成员纠正错误。

**（3）检验预测能否用于新任务和新成员。** 在未用于建模的任务、交互规则及模型组合上评价预测误差，估计预测结果的可信范围。进一步分析哪些行为规律可以跨任务共享，哪些需要重新校准，以及获得可靠预测需要多少样本。对于无法区分的行为原因，保留预测区间，避免让后续机制依赖过于确定的判断。

本部分形成行为预测模型、干预数据与校准方法。研究内容二据此分析成员相互影响后的团队表现；研究内容三则利用预测及其可信范围，估计不同协作安排的收益和风险。

#### 研究内容二 团队交互规律与协作条件

本部分将研究内容一获得的个体行为模型放入完整协作过程，解释为什么某些组合能够互补纠错，另一些组合却会放大错误，并提炼可用于机制设计的条件。

**（1）建立任务分工与信息传递的博弈模型。** 根据任务依赖关系，描述各成员能够看到的信息、可采取的行动，以及行动对共同任务结果的影响。以协同编程为例，分析“实现者提出方案—测试者选择是否独立验证—审查者决定接受或退回”的决策过程。将行为模型用于预测各成员对同伴行动的响应，比较独立判断后共享、即时共享和按需验证等交互方式。

**（2）研究错误传播、分工失效与交互稳定的形成条件。** 改变消息顺序、证据可见范围和验证职责，观察局部错误如何传递到最终结果。重点分析三类情形：成员依赖同一错误建议、多个成员相互等待验证，以及反复修改已经正确的方案。结合有限行动博弈和响应动态分析，研究哪些条件能够抑制上述失效，哪些条件容易使偏差持续放大。均衡与稳定性用于描述成员相互响应的状态，结果质量由独立验证评价。

**（3）确定额外交互和推理投入的收益边界。** 在总预算可比的条件下，分析增加讨论、加强某个成员的推理或引入独立验证，分别能够改善多少任务质量，以及带来多少协调成本。研究能力差异、错误相关性和行为预测误差如何影响这些收益。对于“继续讨论”与“直接验证”等选择，形成与任务条件相联系的判断依据，并通过反例说明适用范围。

本部分形成可检验的协作条件与失效诊断方法。例如，何种证据表明应先独立判断再交流，何时需要补充独立验证，何时继续交互的预期收益已经不足。这些结论作为候选规则的筛选和风险判断依据，进入研究内容三。

#### 研究内容三 协同规则设计与动态调整

本部分综合前两项研究，设计能够根据任务、成员状态和剩余预算调整协作方式的方法，形成可运行、可验证的系统原型。

**（1）把行为预测和协作条件转化为可执行规则。** 构建小规模候选规则库，明确任务与验证职责、信息共享时点、交叉验证要求及停止条件。系统首先利用研究内容一的模型估计各候选规则下的行动和结果，再根据研究内容二的协作条件识别错误传播、验证遗漏等风险。例如，当预测显示测试成员容易受实现者意见影响，且独立检查具有正向收益时，将“先测试、后读取解释”纳入优先比较的候选规则。

**（2）联合选择交互方式和推理预算。** 在总预算约束下，比较将资源用于继续推理、交换证据或独立验证的预期收益，确定当前任务的执行安排。考虑行为预测可能存在误差，对可信程度较低的配置采用保守评价，研究收益提升与失效风险之间的取舍。设置按能力分配、平均分配及不使用博弈模型的自适应方法作为对照，检验前两项研究是否确实改善了决策。

**（3）利用外部结果更新规则并处理环境变化。** 通过测试结果、工具执行反馈和任务完成情况，比较预测与实际表现；偏差持续增大时，重新校准相关成员或调整规则。将更新本身的成本计入预算，并研究任务结束、增益不足或成员变化时的停止与回退条件。例如，讨论未提供新证据时减少重复交互；外部验证仍不通过时继续修正或返回未完成状态。模型更换后，优先补充对规则选择影响最大的校准数据。

本部分形成包含规则选择、预算配置和反馈更新的协同机制。在协同编程任务中，检验其能否在相同总成本下完成更多修复、减少遗漏错误，并在成员变化后以可控开销恢复表现。实际结果同时用于检验行为预测和协作条件，构成三项研究之间的反馈关系。

### 3.2 技术路线

技术路线以同一组任务、行动定义和成本口径连接三项研究：首先从对照实验获得行为数据，建立个体行动预测；随后将预测嵌入团队交互模型，分析规则对错误传播和任务收益的影响；最后据此选择协作规则与预算，并用独立任务结果检验。以下给出各步骤的具体方法。

#### 行为辨识与因素分离

在任务目标、可用信息和行动集合明确时，由推理资源限制或交互信息处理偏差引起的、可重复且可预测的决策偏离，作为本项目研究的有限理性行为。比较基准必须具有同等信息和可行行动，避免用全信息最优解评价局部信息智能体。

| 现象                                 | 首要解释             | 识别措施                                 |
| ------------------------------------ | -------------------- | ---------------------------------------- |
| 缺少关键事实而失败                   | 信息不足             | 向对照组补足信息，保持协议与预算一致     |
| 知道事实但无法完成任务               | 能力或计算限制       | 使用独立求解对照，并逐级改变预算         |
| 在规则重述后表现改善                 | 规则理解或表征限制   | 设置结构化规则与自然语言规则对照         |
| 保持建议内容不变，改变身份后行动变化 | 身份相关响应         | 随机化来源标签，估计效应及置信区间       |
| 保持信息和效用不变，增加互动反而失败 | 协调或交互处理问题   | 使用无交互、延迟披露和独立验证对照       |
| 不按规定效用行事                     | 目标未内化或响应不足 | 先验证收益敏感性，不直接判定为恶意或自利 |

主要辨识策略推理受限与交互信息处理偏差；风险偏好等因素依据先导实验确定是否纳入。身份或顺序引起的响应变化须结合证据质量与任务收益判断。

#### 有限理性博弈模型

本步骤将研究内容一的行为观测转化为研究内容二可使用的模型。模型需要回答：在当前信息、同伴行为和预算下，一个智能体采取不同动作的可能性有多大，以及这些动作对共同任务有什么影响。

设智能体集合为 $`N=\{1,\ldots,n\}`$，任务状态为 $`s_t`$，局部观测为 $`o_{i,t}`$，交互历史为 $`h_{i,t}`$，行动为 $`a_{i,t}`$。机制 $`m_t`$ 决定发言顺序、可见消息、验证要求和停止规则，预算 $`b_{i,t}`$ 决定可用推理资源。有限行动可采用“独立验证、请求证据、执行子任务、移交、提交”等语义动作；自由文本作为动作的参数或证据，由有限行动结构支持博弈分析。

主要任务使用共同外部收益 $`R(s_t,\mathbf a_t)`$，并计入系统计算、通信和失败代价。该收益由任务完成标准定义，不等于模型天然内化的效用。需要通过收益变化实验验证智能体是否对该目标有稳定响应；不满足时，将其视为经验行为策略，并收窄均衡解释。

采用量化响应形式作为候选行为模型：智能体更倾向于选择其判断为有利的行动，同时保留误判或非最优选择的可能。行动概率表示为：

```math
\pi_i(a\mid h_i,m,b_i)=
\frac{\exp\{\lambda_i(h_i,m,b_i)\widehat Q_i(a\mid h_i,m,b_i)\}}
{\sum_{a'\in A_i}\exp\{\lambda_i(h_i,m,b_i)\widehat Q_i(a'\mid h_i,m,b_i)\}}.
```

$`\widehat Q_i`$ 是在局部信息和队友行为判断下的行动价值估计，$`\lambda_i`$ 是选择对价值差异的敏感度。模型应与标准量化响应、认知层级以及不含博弈结构的预测模型比较。[R03](references.md#r03) [R04](references.md#r04)

价值尺度与响应敏感度存在混淆：若同时将 $`\widehat Q_i`$ 乘以常数、将 $`\lambda_i`$ 除以该常数，策略不变。因此先在可控任务中固定收益尺度和参考行动，分别干预信息与预算，再讨论参数辨识。价值估计误差和选择随机性无法区分时，应报告预测分布或等价类。采样温度是生成接口参数，不直接等于 $`1/\lambda_i`$。

#### 交互稳定性与误差传播

本步骤研究个体行动在多轮交互中如何共同变化。若一个成员的小幅判断偏差使其他成员产生更大偏差，错误可能沿交互过程放大；若独立证据能够纠正偏差，团队则可能逐步稳定。分析这些变化，可为信息披露、验证安排和停止规则提供依据。

将一轮交互后的策略分布写为 $`\boldsymbol\pi^{t+1}=F_{m,b,\theta}(\boldsymbol\pi^t)`$，其中 $`\theta`$ 表示待估行为参数。固定点表示模型内的响应一致状态，其博弈均衡含义取决于信念一致性和行为假设。

拟从以下条件分析交互过程的稳定性与误差传播：

1. 在有限行动、连续响应及适当不变域条件下，研究固定点存在性，并分别分析唯一性与可达性。
2. 若在完备不变域内验证 $`F`$ 是压缩映射，可利用压缩映射结论获得该区域内的唯一固定点和迭代收敛。通过反例与干预实验检验其适用范围。
3. 对可微响应映射，研究固定点附近雅可比矩阵的谱半径；小于一可作为局部稳定分析的条件。有限样本估计的谱半径作为经验诊断指标。
4. 在真实与估计响应映射于同一完备不变域内满足共同压缩常数 $`L<1`$、且一致误差不超过 $`\varepsilon`$ 时，可推出固定点距离上界 $`\varepsilon/(1-L)`$。以标准扰动分析为基础，重点将 $`L`$ 与 $`\varepsilon`$ 联系到可测行为和机制变量，并检验其适用条件。

理论效率比较采用同信息、同资源和同可行机制类的基准。低效但稳定的固定点、准确但不稳定的迭代轨迹均需单独讨论。任务持续变化时，以跟踪误差或动态遗憾为目标，分析以环境变化量有界等条件为前提。

#### 信息交互与资源配置

本步骤把前述预测和规律用于实际选择：在剩余预算内，比较不同规则预期能取得的任务质量，并考虑预测不准时可能出现的损失。鲁棒优化用于选择在一组可信行为预测下仍有较好表现的方案。

设 $`\mathcal M`$ 为可实现的协议库，$`\Theta_t`$ 为覆盖候选协议和预算配置的行为响应函数置信集合，$`J`$ 为含成本的任务收益。采用如下鲁棒优化形式：

```math
\max_{m\in\mathcal M,\,\mathbf b}\ \min_{\theta\in\Theta_t}
J\bigl(m,\mathbf b;\theta(m,\mathbf b)\bigr),
\qquad
\sum_i c_i(b_i)+c_{\rm comm}(m)+c_{\rm coord}(m)\leq B.
```

该表达强调响应对协议与预算的依赖。$`\Theta_t`$ 应覆盖候选协议上的响应函数，而非只覆盖原协议的一组参数；对缺少干预数据的配置扩大不确定性范围，以控制外推风险。实际求解可采用有限协议枚举、上下文决策和保守在线更新，在可控计算开销下完成机制更新。

拟构建的有限协议库包括：先独立决策后披露、证据优先披露、按需请求验证、限制重复消息、基于外部验证结果停止。通过实验评价身份匿名化的作用；资源分配采用可观测、可控制的预算档位。

执行流程为：

1. 在校准任务上采集信息、预算与协议的干预数据，估计行为响应及不确定性。
2. 根据任务结构和可用预算，选择具有数据支持的交互协议与资源配置。
3. 记录行动、消息可见范围、工具结果与全部开销，执行有限轮协作。
4. 使用外部可验证反馈更新估计；对异常变化触发重新校准或回退。
5. 在独立测试集上报告任务表现、行为预测误差和预算曲线。

信息设计用于分析证据的披露内容与时机，其应用以任务信息结构、收益与信念假设为依据。[R07](references.md#r07) 信息披露机制控制真实任务证据的可见范围和传递时点。

### 3.3 验证方案

#### 研究假设与检验目标

| 假设                                    | 检验目标                                               |
| --------------------------------------- | ------------------------------------------------------ |
| H1 行为响应依赖任务、协议与预算         | 条件响应模型在留出数据上的预测是否优于固定参数模型     |
| H2 交互结构影响偏差传播                 | 控制证据内容后，身份、顺序与可见性干预是否改变错误传播 |
| H3 个体推理投入与团队收益存在条件性关系 | 不同协议下的边际收益是否存在差异，是否出现非单调变化   |
| H4 行为不确定性建模改善迁移表现         | 同预算下是否降低模型或任务变化引起的性能退化           |

验证围绕最终目标展开：在同一任务集和总成本上限下，检验所提出机制能否提高任务成功率、减少遗漏错误；再比较达到相近质量时的成本，以及成员变化后的性能下降和恢复开销。各项指标同时报告，防止以增加调用或验证成本换取表面提升。主比较对象和成本口径在实验前确定。

上述假设用于解释系统效果的来源：H1 检验研究内容一，H2 和 H3 检验研究内容二，H4 检验研究内容三。模型评价使用留出数据，机制评价使用独立任务结果。

#### 实验任务与设置

构建两层实验体系。第一层为程序生成的分工、协同验证与信息整合任务，明确局部信息、可行行动和收益，以支持因素分离与理论检验。按任务种子及结构划分训练、校准和测试集合，控制模板泄漏。

第二层以协同编程为主要应用：实现者、测试者、审查者共同处理缺陷修复，使用执行结果和隐藏测试评价。SWE-bench 可提供真实软件任务参照，AgentBench 可作为交互评测的补充来源，因果识别由配套干预实验完成。[R27](references.md#r27) [R28](references.md#r28)

主实验先使用二至四个智能体，选择至少三个模型家族，并测量各模型独立能力、错误相关性和成本。具体模型版本在实验启动时冻结。通过更大团队规模检验机制的适用范围。

#### 核心实验与干预

| 实验         | 操纵变量                       | 固定或配对条件                 | 主要观测                           |
| ------------ | ------------------------------ | ------------------------------ | ---------------------------------- |
| 行为辨识     | 预算档位、行动价值差、任务难度 | 信息可见性、模型版本、解码设置 | 响应分布预测、参数可辨识性         |
| 同伴影响     | 建议身份、顺序、措辞           | 建议的事实内容、任务与预算     | 采纳变化、正确转错误率、正确纠错率 |
| 信息不足对照 | 局部或完整信息                 | 任务、协议、模型组合           | 信息约束损失与决策损失的区别       |
| 协同动态     | 信息披露时点、交互轮数         | 团队组成和总预算               | 验证遗漏、动作振荡、收益变化       |
| 预算分配     | 均分、按能力分配、行为模型分配 | 总成本上限和可用工具           | 质量成本前沿、边际收益             |
| 迁移鲁棒性   | 更换队友、难度或协议表达       | 不使用测试标签重新调参         | 性能退化、恢复开销、预测校准       |

补充三组消融实验检验研究内容之间的联系：将行为模型替换为同等数据条件下的直接预测方法，检验研究内容一的作用；取消协作条件对候选规则的筛选，检验研究内容二的作用；取消预测误差处理或反馈更新，检验研究内容三的作用。各组保持总预算、工具权限和候选规则范围可比。

先导实验用于选择主要干预、估计方差和确定样本量；正式实验使用独立数据及预先固定的分析方案。

#### 比较基线与成本控制

单模型基线包括直接求解、自一致性、多次采样加验证和自我修正，以控制额外推理资源带来的收益。[R25](references.md#r25) [R26](references.md#r26) [R29](references.md#r29)

多智能体基线包括同构与异构固定流程、无通信独立集成、延迟披露以及静态有限理性机制。在设定匹配时比较 DICE 等相关方法，并设置同等观测与预算的非博弈自适应控制器，检验博弈建模的增量作用。

所有方法共享允许使用的工具、检索资料和验证权限。协调器、消息压缩器、验证器、失败重试和校准的成本全部记录。跨模型 token 数不能直接视作相同计算量；分别报告费用口径、硬件时间、端到端时延及可测计算量。离线校准成本与在线执行成本分别列示，并报告部署任务量变化时的摊销成本。

#### 评价指标与统计分析

- **任务质量：** 成功率、隐藏测试通过率、缺陷发现率及未发现错误的提交率。
- **协同收益：** 同预算下相对预先选定的强单模型基线的配对差异，以及相对无通信异构集成的增量。
- **行为预测：** 留出集负对数似然、Brier 分数和校准误差。模型自报置信度须经外部结果校准。
- **交互失效：** 验证遗漏、无新增证据的重复动作、正确转错误和错误转正确的频率；指标定义在评测前固定。
- **动态稳定性：** 策略分布变化、动作切换和恢复时间，结合响应模型评价稳定性。
- **鲁棒性：** 未见模型组合和任务上的质量变化、重新校准样本量、额外开销。

按任务配对开展多次独立运行，报告效应量与置信区间。对同一任务中的相关交互采用分层分析或任务级重采样；预先确定主要指标与比较，并对探索性分析控制多重检验。样本量依据先导实验的方差估计、预设效应量与统计功效要求确定。

系统日志保存模型版本、提示模板、采样参数、随机种子、消息可见范围、实际行动、工具结果和资源开销。因果分析以受控干预和外部结果为依据。

#### 研究内容与最终目标的对应关系

| 研究内容                  | 需要验证的结果                                           | 对最终目标的作用               |
| ------------------------- | -------------------------------------------------------- | ------------------------------ |
| 一 个体行为识别与预测     | 能预测未见任务中的行动与错误风险，可信范围与实际误差相符 | 为分工、验证和预算分配提供依据 |
| 二 团队交互规律与协作条件 | 对错误传播、验证遗漏和交互收益的判断得到干预实验支持     | 将个体能力转化为有效的协作安排 |
| 三 协同规则设计与动态调整 | 在同预算下改善任务表现，并控制成员变化后的恢复成本       | 形成可使用、可调整的协同方法   |

理论命题明确任务类与行为假设，经验结果报告独立测试及统计区间。若预测改善未带来系统收益，进一步检查其是否影响了关键决策，以及收益是否被协调成本抵消，据此修正模型或规则。

### 3.4 预期创新与成果

预期创新围绕行为依据、作用规律和设计方法展开。首先，通过信息、规则和预算的对照实验识别决策偏差，建立可用于新任务的行为预测。其次，将个体预测与团队交互联系起来，分析错误传播和有效协作的条件。最后，将这些条件和预测误差共同纳入规则选择，使协作方式能够依据外部结果调整。

项目拟形成三类相互配套的成果：

1. **行为模型与诊断工具**：给出成员在不同信息和资源条件下的行动预测、错误风险及可信范围，配套可复现的校准任务与数据规范。
2. **协作规律与设计准则**：形成具有明确适用条件的理论命题、反例和实验依据，支持信息共享、验证安排及停止条件的选择。
3. **协同机制与系统原型**：实现规则选择、预算分配和反馈更新，并提供与强单模型及固定流程的成本匹配评测。

三类成果最终共同支撑一个可检验的目标：让异构大模型智能体系统能够选择适合当前任务的协作方式，在给定总预算下更可靠地完成任务。具体改进幅度由独立实验确定，并报告协作无优势的任务条件。

### 3.5 实施计划与可行性

| 阶段     | 主要任务                             | 阶段成果                           |
| -------- | ------------------------------------ | ---------------------------------- |
| 第一阶段 | 个体行为对照实验、预测建模与校准     | 行为数据规范、辨识方法与预测基线   |
| 第二阶段 | 团队交互分析、有效协作条件与规则设计 | 理论命题、适用边界及机制原型       |
| 第三阶段 | 协同机制实现、反馈更新与协同编程评测 | 预算匹配实验、系统原型及可复现成果 |

研究以冻结模型、有限行动与小规模协议库为起点，逐步扩展至动态任务。模型接入与资源测量可依托训练和推理工具实现；行为微调作为后续扩展，单独核算训练成本。先导实验优先检验协议干预是否产生可重复的行为变化，以及行为模型是否具有留出预测能力，据此确定后续分析的模型复杂度与实验规模。

### 3.6 研究风险与应对

| 主要风险                     | 应对方法                                       |
| ---------------------------- | ---------------------------------------------- |
| 响应模型拟合不足或参数不可分 | 比较认知层级与半参数模型，报告等价类或预测区间 |
| 行为变化主要由信息质量解释   | 调整为信息结构与预算耦合分析，修正行为假设     |
| 理论条件覆盖范围有限         | 区分可证明任务类与经验适用范围，以反例明确边界 |
| 协同增益不足或校准成本偏高   | 研究启用与停止条件，采用参数共享和保守回退     |
| 模型版本变化影响复现         | 固定权重或记录接口版本，开展版本迁移测试       |

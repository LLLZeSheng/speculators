# 申请完善说明

本目录提供围绕“增强异构大模型智能体系统协同推理能力”的研究方案论证与文献依据。正文保留约定的三部分结构，具体申请类别、申报年度、申请代码及申请人前期工作尚未确定。本说明集中记录转为正式申请材料时需要完成的事项。

## 1. 与青年基金申请书的对应关系

截至2026年10月7日核查，2026年青年科学基金项目（C类）申请书正文调整为“立项依据、研究内容、研究基础”，正文原则上不超过30页，鼓励简洁表达；研究内容可按研究逻辑自主组织。[自然科学基金委申请书改版说明](https://www.nsfc.gov.cn/p1/3381/2821/99242.html)

本方案可按以下关系整理入正式模板。若申报下一年度项目，应使用届时发布的指南和系统模板，不能将本说明视为尚未发布年度的要求。

## 2. 研究基础应如何补实

研究基础应说明已有工作怎样降低本项目的实施不确定性。建议围绕三个研究环节组织真实材料，而非罗列成果数量。

| 对应研究                   | 有说服力的已有基础                                   | 本人贡献与关联的写法                                     |
| -------------------------- | ---------------------------------------------------- | -------------------------------------------------------- |
| 信息价值评估与有限理性决策 | 决策建模、行为评测、实验设计或统计辨识方面的成果     | 说明已有方法如何支持信息价值参照、评估偏差检验与决策预测 |
| 策略交互与协同纠错机理     | 博弈建模、多智能体学习、决策理论或理论分析方面的成果 | 说明已掌握的分析工具、具体条件和本项目需要突破的差距     |
| 信息披露与验证机制         | 智能体交互、代码任务评测、工具执行或可复现实验平台   | 说明实际已具备的组件、可用模型与资源，以及尚需建设的内容 |

每项成果应对应可核验的论文、代码、实验记录或平台材料。不能由仓库中存在模型训练代码，推断申请人已具有多智能体协同研究成果；也不能把本方案拟开展的实验写成已完成结果。

工作条件宜写明可实际使用的模型版本、计算设备或API额度、执行环境和人员投入，并据此核算关键比较的成本。本稿没有将未经确认的算力、合作关系或个人成果写入正文。

## 3. 最有价值的先导证据

以下是补强立项依据的实验建议，均为待开展工作。

**第一，给出一组固定信息条件下的行为差异。** 在同一批具有确定答案的任务上，对比直接共享结论、先共享证据、核验后共享三种安排，报告核验概率及纠错、误导的变化。按初始正确性分组可帮助解释条件效应，但运行机制不能获得当前答案是否正确的标签。

**第二，给出一组核验依赖的反事实比较。** 对同一任务随机指定不同成员完成或不完成检查，估计四种核验组合的结果，检查互补或替代关系是否真实存在。任务环节不同、证据来源不同和核验收益互补是不同性质，应分别记录。

**第三，给出一张同预算比较表。** 至少包含强单模型、无通信异构集成、固定独立核验及一个简化联合机制，报告任务质量、置信区间与完整成本。此表用于判断研究是否具有实际改进空间，而非提前承诺某个提升比例。

先导阶段还应检查输出解析、提示变化、核验动作执行及隐藏测试隔离。正式实验的任务数、重复数与主要比较应由先导方差和功效分析确定；同一任务的重复采样不能当作独立任务扩大样本量。

## 4. 正式材料的取舍

报告的中心问题应始终保持为“有限理性条件下，成员对信息与核验价值的判断如何通过相互决策影响协同推理”。个体决策建模提供依据，博弈分析解释策略依赖与证据获取的反馈，机制设计据此组织信息交互和验证分工，并检验系统能力是否得到改善。研究内容突出这些问题的递进关系，实验变量和操作细节置于技术路线。若前期基础较弱，优先保留二智能体可控模型和代码诊断验证，进一步压缩模型数量与机制集合。

正文不需要容纳全部51项文献的介绍。保留与科学问题、最直接竞争工作和关键方法有关的引用，其余书目作为研究储备；预印本结论保持条件性表述。正式稿还应核对题名、作者、出版信息、所用版本和对应论断，不能仅检查链接是否可打开。

## 5. 文稿属性与人工核验

本轮文献整理与研究方案论证使用了生成式人工智能辅助。正式申请前，申请人需要亲自核实引用和论证，结合本人研究作出实质性修改并负责最终文本。

2026年度申请通告要求，对利用生成式人工智能跟踪研究动态、整理文献得到的信息进行人工核验并如实声明使用情况，同时明确不得使用由生成式人工智能直接生成的申请书。因此，本目录定位为研究准备与论证材料，不应原样作为正式申请书提交。[2026年度申请通告，申请人与主要参与者事项第8条](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

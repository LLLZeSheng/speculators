# 异构大模型智能体系统的有限理性博弈与协同机制研究

本目录收录基金研究方案，围绕有限理性行为辨识、异构策略交互机理与协同机制设计，研究信息交互和推理资源配置对智能体系统稳定性及协同效率的影响。

**报告结构：1. 摘要；2. 拟解决的问题及其重要性；3. 研究内容、技术路线与验证方案。**

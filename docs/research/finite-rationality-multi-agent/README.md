# 异构大模型智能体系统的有限理性博弈与协同机制研究

本项目旨在形成一套能够根据任务、成员能力和可用预算调整的协同方法，使异构大模型智能体系统在相同资源投入下更可靠地完成复杂任务。研究依次回答三个问题：成员会怎样行动，这些行动如何影响团队，以及如何据此改进分工、信息交换、验证和预算分配。

**报告结构：1. 摘要；2. 拟解决的问题及其重要性；3. 研究内容、技术路线与验证方案。**

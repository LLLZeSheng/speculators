# 有限理性与异构大模型智能体协同研究报告

本目录收录基金选题论证报告，重点研究交互协议与推理预算如何影响大模型智能体的决策行为，以及由此产生的协同效率与稳定性问题。

**推荐题目：有限理性下异构大模型智能体的协同决策机理与交互机制设计。**

| [literature-matrix.md](literature-matrix.md) | 直接相关工作对照、适用条件和最小验证证据                                                                     |

报告日期：2026年10月6日。本文为研究方案论证，不包含新开展的训练、实验或已证明的新定理。主要场景为共同收益的多Agent协作，跨机构支付与契约设计作为可选扩展。

阅读顺序建议为完整报告、文献对照表、参考文献。正文引用编号R01至R30与参考文献清单一一对应；正式发表版本与预印本在条目中分别说明。

# 异构大模型智能体系统的有限理性博弈与协同机制研究

本目录收录青年基金研究方案及文献依据，以增强异构大模型智能体系统的协同推理能力为主线，研究成员如何依据任务价值和同伴策略选择工作，以及分工与信息交互如何共同影响系统结果。

三项研究依次为：**有限理性博弈建模与策略响应辨识、任务分工与信息交互的均衡分析、基于均衡分析的协同机制与策略更新。** 第一项建立行为依据，第二项解释有效或低效协作的形成条件，第三项据此设计任务协调和策略更新方法。通过同信息、同预算及同校准数据比较，检验博弈结构相对工作流、协作图优化、动态路由和其他自适应方法的贡献。

# 异构大模型智能体系统的有限理性博弈与协同机制研究

本目录收录基金研究方案，围绕异构大模型智能体系统协同推理能力的提升，依次研究有限理性行为辨识、异构策略交互机理与协同推理机制。三项研究通过行为预测、机理分析和机制反馈相衔接，探索促进信息整合、推理分工与交叉纠错的方法。

**报告结构：1. 摘要；2. 拟解决的问题及其重要性；3. 研究内容、技术路线与验证方案。**

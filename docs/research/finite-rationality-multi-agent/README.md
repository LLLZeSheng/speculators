# 异构大模型智能体系统的有限理性博弈与协同机制研究

本目录收录青年基金研究方案及文献依据，围绕异构大模型智能体系统协同推理能力的提升，研究证据交互如何改变核验选择，以及核验产生的新证据如何影响推理衔接与交叉纠错。

三项研究依次为：**有限理性响应辨识、核验博弈与纠错机理、信息披露与验证机制设计。** 前一部分提供后一部分所需的行为依据和选择条件，通过可控任务与协同代码诊断检验整体研究链条。

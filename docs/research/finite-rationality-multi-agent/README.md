# 异构大模型智能体系统的有限理性博弈与协同机制研究

本目录收录青年基金研究方案及文献依据，围绕异构大模型智能体系统协同推理能力的提升，研究成员如何评估同伴信息与核验增益、这些判断如何转化为相互依赖的决策，以及信息交互与验证分工如何促进证据整合和交叉纠错。

三项研究依次为：**信息价值评估与有限理性决策机理、策略交互与协同纠错机理、信息披露与验证机制设计。** 第一项提供个体决策模型，第二项解释相互决策的系统效应，第三项依据这些规律组织协作，通过可控推理任务与协同代码诊断检验整体研究链条。

# 文献研读、研究定位与验证依据

本轮围绕任务分工与信息交互重新组织研究定位。博弈要素、实际策略响应和均衡质量构成主线；动态工作流与路由是必要对照，辩论和核验作为具体交互与行动保留。

本表服务于一个具体问题：**能力异构与有限理性条件下，任务分工和信息交互如何通过策略依赖影响协同推理？** 研究定位由原论文的模型、方法与实验共同约束。“拟研究增量”是本项目需要证明和验证的内容，不代表已经取得相应结果，也不代表相关方向此前无人研究。第5节列出关键术语的原文依据、本文含义与适用边界。

R18的异构实验采用生成时随机选择模型，并包含相对同构系统平均表现的比较；本项目固定成员组合并允许职责调整，以开发集选定的最强成员基线检验增量。R17除失败分类外，已开展提示与系统组织方式的干预案例，不能把加入核验角色或开展干预本身作为创新。

R29对问题难度的估计使用大量采样，原始研究明确将部分难度估计开销留作后续问题；本项目重新评价时将该开销纳入预算。R27原始评测要求相关失败测试转为通过，并保持原有通过测试；本项目同时记录未检出的错误与不必要修改，不把通过有限测试表述为形式正确性证明。

R49第3至5节及附录区分代码解释与测试反馈，其MBPP实验保留部分测试用于独立评价。R50第3节已有根据测试反馈切换计划与调试的交互，第6.3节及第8节明确讨论调用开销；其“检索”由模型生成相似例子，不等于取得新的外部事实。两项工作的程序生成结果均不能直接视为仓库修复效果。

## 4. 本项目必须建立的证据链

1. **博弈模型能够预测成员行为。** 有限任务图给出可选行动与依赖，独立执行估计联合收益，受约束模型预测任务选择；通过留出干预检验，不仅比较训练拟合度。
2. **策略相互依赖影响分工与结果。** 在匹配信息和能力条件下改变同伴行动，检查收益关系、关键任务覆盖与实际响应；随机披露和任务承担检验信息直接作用及分工反馈。
3. **均衡性质与推理质量分别得到证据支持。** 在可枚举模型中比较相同权限下的团队最优、局部均衡和量化响应；自然任务的近似残差附带估计误差，不从语言一致推断均衡或正确性。
4. **机制执行符合建模对象。** 记录任务建议、成员接受和实际完成，区分大模型自然选择与局部控制模块实施的策略，计入协调和执行失败。
5. **博弈结构的贡献经得起公平比较。** 对齐任务图、候选调整、校准数据和预算，与强单模型、图优化、动态路由及非博弈自适应控制比较；有限更新的收益独立测量。
6. **理论和方法具有明确边界。** 保留无效区间与反例，对模型失配、成员变化和任务结构迁移分别评价。两阶段随机比较不在缺少额外假设时被表述为完全识别自然间接效应。

## 直接比较中必须保留的条件

DICE 中的唯一性和收敛分析具有正则化、单调性及相关正则条件；这些条件不能简写成“任意多Agent系统均可稳定协作”。比较时应对齐动作定义、信息、预算和协调器能力，并说明理论对象与实际冻结模型之间的关系。[DICE全文](https://arxiv.org/html/2606.08068v2)

量化响应决策聚合中的特定信号条件决定了结论适用范围。不能由该结果推断“随机性越强，集体智能越好”，也不能直接将生成接口温度解释为一般任务中的理性程度。[决策聚合全文](https://arxiv.org/html/2603.13807v1)

能力与合作行为的区分来自具体实验设计。将这一区分迁移到新任务时，应重新验证规则理解、能力匹配和收益敏感性，避免把执行失败一律解释为策略性不合作。[零成本协作论文](https://proceedings.mlr.press/v306/yadav26a.html)

## 选题成立的最小证据

1. 至少一种协同失效在信息、预算与版本固定后能够重复出现。
2. 协议或资源干预能够解释行为变化，并排除任务信息变化这一替代解释。
3. 行为模型对留出任务或未见队友有预测价值，而不仅是对已见数据的拟合。
4. 自适应机制在同等预算下优于强单模型、固定协议及非博弈自适应基线中的合理比较对象。
5. 对无优势的任务明确给出适用边界，允许机制选择不协作或提前停止。

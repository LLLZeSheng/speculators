# 文献研读、研究定位与验证依据

本表服务于一个具体问题：**信息披露如何改变异构智能体的核验选择，核验产生的证据又如何影响后续协同推理？** 研究定位由原论文的模型、方法与实验共同约束。“拟研究增量”是本项目需要证明和验证的内容，不代表已经取得相应结果，也不代表相关方向此前无人研究。

R18的异构实验采用生成时随机选择模型，并包含相对同构系统平均表现的比较；本项目固定成员及职责，以开发集选定的最强成员基线检验增量。R17除失败分类外，已开展提示与系统组织方式的干预案例，不能把加入核验角色或开展干预本身作为创新。

R29对问题难度的估计使用大量采样，原始研究明确将部分难度估计开销留作后续问题；本项目重新评价时将该开销纳入预算。R27原始评测要求相关失败测试转为通过，并保持原有通过测试；本项目同时记录未检出的错误与不必要修改，不把通过有限测试表述为形式正确性证明。

R49第3至5节及附录区分代码解释与测试反馈，其MBPP实验保留部分测试用于独立评价。R50第3节已有根据测试反馈切换计划与调试的交互，第6.3节及第8节明确讨论调用开销；其“检索”由模型生成相似例子，不等于取得新的外部事实。两项工作的程序生成结果均不能直接视为仓库修复效果。

## 4. 本项目必须建立的证据链

1. **行为有可辨识的差异。** 固定事实、预算、候选池与版本后，结论披露能否产生可重复的核验响应变化；模型能否预测留出的干预条件。
2. **差异通过明确路径影响结果。** 两阶段随机实验分别测量总效应、指定核验条件下的受控效应及其交互。未满足额外条件时，不将其称为已分离的自然间接效应。
3. **博弈结构提供额外预测。** 联合预测核验组合的收益及成员响应，与使用相同数据的非博弈模型比较，检验未见任务或成员组合上的表现。
4. **机制收益经得起强基线与预算控制。** 比较固定核验、证据协作、集中式推理及自适应控制，明确质量收益、协调成本与校准成本。
5. **理论与机制具有可检验的边界。** 保留无增益区间、模型失配与反例，依据数据限定结论，不以共识增强代替正确性提升。

## 5. 研读和引用范围

本轮查看了直接相关论文的模型或机制、核心实验与适用条件，并对DICE、量化响应聚合、QRE辨识及部分社会学习工作的关键理论段落作交叉核对；实验设计同时参考CoVe、Smit等比较研究、推理计算分配和SWE-bench的评测说明。此处记录原文研读与方案分析，不表示已经复现论文实验，也不表示逐项审计全部证明。

R36和R40采用已核对的v2；正式发表论文按出版信息标注。预印本、作者存档稿与正式论文的区别见[书目](references.md)。索引中的其余条目用于理论背景、框架或扩展阅读，正文不以综述替代具体方法的原始出处。
